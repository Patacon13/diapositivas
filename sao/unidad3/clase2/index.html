EL PODER DE LA REPETICIÓN: Bucles en Java

"Los ciclos nos permiten repetir instrucciones de manera sencilla. Podemos hacerlo una determinada cantidad de veces o mientras se cumpla una condición."

Sin Bucles (Código Repetitivo)

Copiar y pegar sentencias 100 veces satura el archivo, dificulta el mantenimiento y hace imposible responder a entradas dinámicas del usuario.

Con Bucles (Automatización)

Una única instrucción se reitera automáticamente las veces que sea necesario, ahorrando líneas y adaptándose al volumen de datos en memoria.

MAPA DE CICLOS: while, do-while y for

Bucle while

Test Pre-Bucle (0 a N)

Evalúa la condición antes de ingresar. Si la premisa es falsa de entrada, el código jamás se ejecuta (0 vueltas).

Bucle do-while

Test Post-Bucle (1 a N)

Ejecuta el bloque primero y evalúa la condición al final. Se garantiza que el código corre al menos una vez.

Bucle for

Ciclo Exacto (N Vueltas)

Diseñado para iterar una cantidad fija conocida de antemano. Integra inicio, condición y modificación en su cabecera.

CICLO WHILE: Repetición Condicional

Tiene una estructura análoga al condicional if, pero tras completar el bloque, re-evalúa la condición: 


while (condicion) {
    // Código que se ejecutará en cada repetición

    // ACCIÓN CRUCIAL: Modificar alguna variable que influya
    // en la condición para que eventualmente se vuelva false.
}
El contrato del while

Mientras la expresión entre paréntesis resulte true, el procesador vuelve a saltar al inicio del bloque. En cuanto sea false, continúa con la línea inmediatamente posterior a la llave de cierre.

ALERTA CRÍTICA: El Loop Infinito

¿Qué ocurre si la condición jamás se vuelve falsa?

Se produce un bucle infinito. El programa ejecuta ese fragmento eternamente, consumiendo el 100% de un núcleo de la CPU y congelando la aplicación hasta que el sistema operativo o el usuario fuercen su terminación.

❌ ERROR: Olvidar el incremento 

int contador = 1;
while (contador <= 5) {
    System.out.println(contador);
    // ¡Falta contador++!
    // contador siempre vale 1: ¡loop infinito!
}
✔ CORRECTO: Progreso hacia el corte 

int contador = 1;
while (contador <= 5) {
    System.out.println(contador);
    contador++; // Modifica el estado
    // A la 6ta vuelta, la condición da false
}

CICLO DO-WHILE: Garantía de al menos 1 vuelta

Se diferencia del while en que la condición se evalúa en el pie del bucle: 


do {
    // Código que se ejecutará en cada repetición
    // Se ejecuta AL MENOS UNA VEZ, sin importar la condición inicial

    // Modificar condición
} while (condicion); // ¡Ojo: punto y coma obligatorio al final!
El caso de uso predilecto: Menús de Usuario

En un menú de consola siempre debemos mostrar las opciones y pedir la entrada al menos una vez antes de verificar si el usuario eligió salir.

Requerimientos de Mejora

Pedir al usuario que valore la película mostrándole el menú de forma indefinida hasta que ingrese 9 para salir:

Opciones de Calificación:
0: Muy Mala • 1: Mala • 2: Mediocre
3: Buena • 4: Muy Buena
9: Salir del sistema
Comportamiento:
• Al presionar 9: Agradece y finaliza.
• Valor incorrecto: "Opción incorrecta, vuelva a intentarlo."
• El menú se vuelve a mostrar inmediatamente.

CALIPEL v2: Solución con do-while


import java.util.Scanner;

public class CalipelMenu {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        int opcion;

        do {
            System.out.println("\n=== MENÚ CALIPEL ===");
            System.out.println("0-Muy Mala | 1-Mala | 2-Mediocre | 3-Buena | 4-Muy Buena | 9-Salir");
            System.out.print("Ingrese una opción: ");
            opcion = entrada.nextInt();

            if (opcion == 9) {
                System.out.println("¡Gracias por utilizar CALIPEL! Hasta pronto.");
            } else if (opcion == 0) {
                System.out.println("Calificación: MUY MALA. Lo lamentamos.");
            } else if (opcion >= 1 && opcion <= 4) {
                System.out.println("Calificación registrada con éxito.");
            } else {
                System.out.println("Opción incorrecta, vuelva a intentarlo.");
            }
        } while (opcion != 9);
    }
}

DESAFÍO CALIPEL v3: 3 Errores Consecutivos

Regla de Bloqueo por Fallas Consecutivas

A la 3ra vez consecutiva que el usuario ingrese un valor inválido, la aplicación finaliza indicando: "Ingresaste tres valores consecutivos inválidos, CALIPEL se cierra."

El reseteo del contador

Si el usuario comete 1 o 2 errores pero luego ingresa un valor correcto (0-4 o 9), el contador de fallas vuelve a 0 inmediatamente.

CALIPEL v3: Contador de Fallas Consecutivas


import java.util.Scanner;

public class CalipelSeguro {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        int opcion, fallasConsecutivas = 0;

        do {
            System.out.println("CALIPEL | 0-4 Valorar | 9 Salir:");
            opcion = entrada.nextInt();

            if (opcion == 9) {
                System.out.println("Salida exitosa.");
            } else if (opcion >= 0 && opcion <= 4) {
                System.out.println("Valoración registrada.");
                fallasConsecutivas = 0; // ¡Reseteo al acertar!
            } else {
                fallasConsecutivas++;
                System.out.println("Opción incorrecta (" + fallasConsecutivas + "/3)");
                if (fallasConsecutivas == 3) {
                    System.out.println("Ingresaste tres valores consecutivos inválidos, CALIPEL se cierra.");
                    break; // Corta el bucle inmediatamente
                }
            }
        } while (opcion != 9);
    }
}

CICLO FOR: Estructura Básica

Consta de 3 partes delimitadas por punto y coma dentro de los paréntesis: 


for ( inicio ; condicion ; modificador ) {
    // Código que se repetirá en cada vuelta
}

1. Inicio

Se ejecuta una única vez al arrancar el ciclo. Declara e inicializa la variable contadora (ej: int vuelta = 1).

2. Condición

Se evalúa antes de cada vuelta. Si es verdadera continúa; si es falsa, finaliza el ciclo (ej: vuelta <= 4).

3. Modificador

Se ejecuta al final de cada iteración. Modifica el contador (ej: incremento con vuelta++).

CICLO FOR: Ejemplo de Contar 1 a 4


for (int vuelta = 1; vuelta <= 4; vuelta++) {
    System.out.println("Dando la vuelta número: " + vuelta);
}
Consola de salida:
Dando la vuelta número: 1
Dando la vuelta número: 2
Dando la vuelta número: 3
Dando la vuelta número: 4
Total de iteraciones exactas

El contador arranca en 1 y se detiene cuando llega a 5 (5 <= 4 es falso). El bucle realiza exactamente 4 repeticiones.

for (int fila = 0; fila < n; fila++) {
