FLUJO DE EJECUCIÓN: Control de Instrucciones

Las estructuras de control permiten definir el orden y la forma en que se ejecutan las sentencias de un programa:

Flujo Lineal (Secuencial)

Las instrucciones se ejecutan estrictamente una tras otra, desde la primera línea hasta la última, sin posibilidad de evaluar desvíos ni repetir tareas.

paso1(); → paso2(); → paso3();

Flujo Ramificado (Flexible)

El programa evalúa expresiones booleanas para decidir qué bloque de código ejecutar, omitir otros y responder de forma adaptativa a los datos.

if (condición) { opciónA(); } else { opciónB(); }
El corazón del software moderno

Sin estructuras de control, un programa sería una simple calculadora de una sola pasada. La toma de decisiones permite validar entradas, reaccionar a eventos y modelar reglas de negocio.

MAPA CONCEPTUAL: Estructuras Algorítmicas

Secuenciales

Acciones ejecutadas en serie sin bifurcaciones:

  • Entrada de datos (Scanner)
  • Asignación y cálculos
  • Salida por pantalla (println)

Condicionales (Selectivas)

El flujo se divide según una condición booleana:

  • Selección simple (if)
  • Selección completa (if-else)
  • Selección anidada (en cascada)
  • Selección múltiple (switch)

Cíclicas (Repetitivas)

Reiteran un bloque de instrucciones:

  • while (repetir mientras)
  • do-while (repetir hasta)
  • for (repetir para un rango exacto)

ESTRUCTURAS SELECTIVAS: Toma de Decisiones

Permiten evaluar una o más condiciones booleanas y ejecutar distintas acciones según el resultado (true o false):

Selección Simple (1 Camino)

if (condicion) {
    ejecutarAccion();
}
// Si es false, continúa de largo

Sólo se actúa si se cumple la premisa.

Selección Completa (2 Caminos)

if (condicion) {
    accionVerdadera();
} else {
    accionFalsa();
}

Bifurcación obligatoria: o ocurre A, o ocurre B.

SELECCIÓN SIMPLE: Condición Única

Analogía Cotidiana 1

"Si hay sol, vamos a la plaza." 


// Condición booleana simple:
boolean haySol = true;

if (haySol) {
    System.out.println("Vamos a la plaza");
}
Analogía Cotidiana 2

"Si hay sol Y es sábado, vamos a la plaza y alimentamos palomas." 


// Condición booleana compuesta con conector &&:
boolean haySol = true;
boolean esSabado = true;

if (haySol && esSabado) {
    System.out.println("Vamos a la plaza");
    System.out.println("Alimentamos palomas");
}

SINTAXIS JAVA: Instrucción if

La palabra reservada if evalúa una expresión booleana que obligatoriamente va entre paréntesis:

1. Estructura con bloque (Recomendada)


if (condicion) {
    // Bloque delimitado por llaves { }
    // Permite una o múltiples instrucciones
    instruccion1();
    instruccion2();
}

2. Instrucción única en una línea


if (condicion) instruccionUnica();

// Aunque Java lo permite sin llaves para una sola
// sentencia, la buena práctica exige usar llaves {}
// para evitar errores lógicos al agregar líneas.
¡Cuidado con el punto y coma accidental!

Escribir if (condicion); con un punto y coma al final crea una sentencia vacía: el bloque posterior se ejecutará siempre, anulando el efecto del condicional.

SELECCIÓN COMPLETA: Bifurcación if - else

Escenario Excluyente

"Si hay sol vamos a la plaza, sino vamos al cine." 


boolean haySol = true;

if (haySol) {
    // Rama VERDADERA (true)
    System.out.println("Vamos a la plaza");
} else {
    // Rama FALSA (false)
    System.out.println("Vamos al cine");
}
Exclusión mutua

La cláusula else jamás se ejecuta por su cuenta: representa la negación estricta de la condición del if. El flujo entrará exactamente a una de las dos ramas.

SELECCIÓN ANIDADA: Decisiones en Cascada

Cuando existen más de dos alternativas excluyentes, encadenamos else if: 


boolean haySol = false;
int saldo = 1500;
boolean pagoNetflix = true;

if (haySol) {
    System.out.println("Vamos a la plaza");
} else if (saldo > 20000) {
    System.out.println("Vamos al cine");
} else if (pagoNetflix) {
    System.out.println("Miramos una película en casa");
} else {
    System.out.println("Escuchamos música en la radio");
}
Evaluación cortocircuitada en cascada

En cuanto una condición resulta true, Java ejecuta su bloque correspondiente y salta automáticamente al final de toda la estructura, ignorando las condiciones restantes.

CASO DE ESTUDIO: CALIPEL (Valoración de Pelis)

Enunciado del Problema

Desarrollar una aplicación en Java que solicite al usuario ingresar una calificación numérica del 0 al 4 para la película que acaba de ver:

Valor Ingresado Calificación Mensaje Mostrado
0Muy MalaLo lamentamos mucho.
1MalaLo lamentamos.
2MediocreTrabajaremos para mejorar.
3BuenaTrabajaremos para mejorar.
4Muy BuenaNos alegramos mucho.
Cualquier otroInválido"Ingresaste un valor no válido"

CALIPEL: Solución con if - else if


import java.util.Scanner;

public class CalipelIf {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        System.out.print("Ingrese la valoración de la película (0-4): ");
        int puntajePeli = entrada.nextInt();

        if (puntajePeli == 0) {
            System.out.println("Calificaste como MUY MALA. Lo lamentamos mucho.");
        } else if (puntajePeli == 1) {
            System.out.println("Calificaste como MALA. Lo lamentamos.");
        } else if (puntajePeli == 2) {
            System.out.println("Calificaste como MEDIOCRE. Trabajaremos para mejorar.");
        } else if (puntajePeli == 3) {
            System.out.println("Calificaste como BUENA. Trabajaremos para mejorar.");
        } else if (puntajePeli == 4) {
            System.out.println("Calificaste como MUY BUENA. Nos alegramos mucho.");
        } else {
            System.out.println("Ingresaste un valor no válido.");
        }
    }
}

SELECCIÓN MÚLTIPLE: Estructura switch

El switch propone una sintaxis mucho más limpia y legible cuando comparamos una misma variable contra múltiples constantes discretas: 


switch (expresion) {
    case valor1:
        // sentencias si expresion == valor1
        break;
    case valor2:
        // sentencias si expresion == valor2
        break;
    case valor3:
        // sentencias si expresion == valor3
        break;
    default:
        // sentencias si ningún caso coincidió
        break;
}

¿Qué tipos soporta switch?

  • Tipos enteros: byte, short, int
  • Caracteres: char
  • Cadenas de texto: String (desde Java 7)
  • No soporta boolean ni punto flotante (float, double)

ANATOMÍA DEL SWITCH: case, break y default

case valor:

Define los puntos de entrada para cada valor constante. Los valores deben ser únicos y computables en tiempo de compilación.

break;

¡Crucial! Detiene la ejecución y sale del bloque switch. Si se omite, ocurre fall-through: la ejecución "cae" al siguiente caso sin evaluar.

default:

Rama opcional de escape equivalente al else final. Se ejecuta si ninguna etiqueta case coincidió con la expresión.

El fenómeno del Fall-Through (Caída de Casos)

A diferencia de lenguajes más modernos, en Java clásico cada case requiere explícitamente su instrucción break;. Omitirlo es un error frecuente de novatos.

CALIPEL REFACTORIZADO: Solución con switch


import java.util.Scanner;

public class CalipelSwitch {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        System.out.print("Ingrese la valoración de la película (0-4): ");
        int puntajePeli = entrada.nextInt();

        switch (puntajePeli) {
            case 0:
                System.out.println("Calificaste como MUY MALA. Lo lamentamos mucho.");
                break;
            case 1:
                System.out.println("Calificaste como MALA. Lo lamentamos.");
                break;
            case 2:
            case 3: // Casos agrupados: comparten el mismo bloque de código
                System.out.println("Calificaste como MEDIOCRE o BUENA. Trabajaremos para mejorar.");
                break;
            case 4:
                System.out.println("Calificaste como MUY BUENA. Nos alegramos mucho.");
                break;
            default:
                System.out.println("Ingresaste un valor inválido.");
                break;
        }
        System.out.println("¡Gracias por visitar CALIPEL!");
    }
}
