TIPOS DE DATOS: Clasificación en Java

Primitivos

Almacenan directamente el valor en memoria. No son objetos, no tienen métodos asociados.

byte short int long float double char boolean

No Primitivos (Objetos y Referencias)

Guardan referencias a direcciones de memoria. Poseen métodos y requieren invocación o `new`.

Tipos Envoltorio (Wrappers):
Byte Short Integer Long Float Double
Colecciones y Biblioteca:
Arrays [] String ArrayList Scanner
Definidos por Usuario:
Persona Animal

ELECCIÓN ADECUADA: El Efecto Y2K

WEEKLY WORLD NEWS • SPECIAL REPORT
JANUARY 1, 2000
THE DAY THE EARTH WILL STAND STILL!

"The computer crash of the millennium: banks, flights and satellites threatened by a 2-digit date representation."

Y2K

¿Por qué ocurrió?

Para economizar unos pocos bytes de memoria en los años 60 y 70, los años se almacenaban con 2 dígitos (ej: 99 en vez de 1999).

Al pasar al 2000, los sistemas volvían al 00 (año 1900), provocando fallas masivas. Costó más de $300 mil millones de dólares corregirlo en todo el mundo.

DESBORDAMIENTO: [Overflow]

Ocurre cuando el resultado de una operación aritmética excede el rango máximo que puede representar un tipo de dato. 


// Rango de short (16 bits): -32,768 a 32,767
short x = 32767;            // Valor máximo permitido
short y = (short)(x + 1);    // ¡Se pasa de largo!

System.out.println(y);      // Imprime: -32768 (¡desbordó!)

💡 En palabras simples: Como la cantidad de bits es fija, el valor "se da la vuelta" (wrap-around) como el cuentakilómetros de un auto y reaparece en el extremo negativo mínimo.

SUBDESBORDAMIENTO: [Underflow]

Ocurre cuando el resultado de una operación es menor que el valor mínimo representable por el tipo de dato. 


// Rango de short (16 bits): -32,768 a 32,767
short x = -32768;           // Valor mínimo permitido
short y = (short)(x - 1);    // ¡Cae por debajo del límite!

System.out.println(y);      // Imprime: 32767 (¡subdesbordó!)

💡 Comportamiento simétrico: Al restar por debajo de la cota inferior, el valor "salta" hacia el límite superior positivo más alto.

VARIABLES: La Analogía de las Cajas

edad = 2
peso = 4.5
esMacho = true
nombre = "Misi"
[Disponible]
vidas = 7
  • La Caja: Representa una posición específica en la memoria RAM del ordenador.
  • La Etiqueta: Es el nombre (identificador) de la variable con el que nos referimos a ella en el código.
  • El Tamaño / Forma: Es el Tipo de Dato (determina si puede entrar un número chico, grande o texto).
  • El Contenido: Es el Valor actual. Puede cambiar cuantas veces sea necesario a lo largo del tiempo.

IDENTIFICADORES: Reglas y Convenciones

Identificador Convención de Nomenclatura Ejemplos Válidos
Nombre de variable Comienza con minúscula. Si tiene varias palabras, se usa camelCase. numAlumnos, sumaTotal
Nombre de constante Todo en MAYÚSCULAS separadas por guión bajo (SCREAMING_SNAKE_CASE). TAM_MAX, PI, DIAS_SEMANA
Nombre de una clase Comienza con Mayúscula (PascalCase). Generalmente sustantivos. String, MiClase, Scanner
Nombre de función / método Comienza con minúscula (camelCase). Generalmente verbos de acción. modificaValor(), obtieneResultado()

CONSTANTES: Palabra reservada final

Una constante almacena un valor que no puede modificarse tras su inicialización. En Java se define con final: 


// Enteros                                // Punto flotante y carácter
final byte  EDAD_MINIMA = 18;             final float  IVA   = 0.21f;
final short MAX_ALTURA  = 250;            final double PI    = 3.14159;
final int   DIAS_SEMANA = 7;              final char   GRADO = '°';
final long  DISTANCIA_SOL = 149_600_000L;

🔒 Garantía de inmutabilidad: Si se intenta reasignar una constante (ej: EDAD_MINIMA = 21;), el compilador detendrá la ejecución con un error.
