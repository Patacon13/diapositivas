Modularización en Java // APIs y Paquetes

Una API (Application Programming Interface) es un conjunto de clases y métodos reutilizables. Java organiza sus bibliotecas estándar en paquetes (packages) jerárquicos:

java.lang
Math, String, System
(Import automático)
java.util
Scanner, Random
(Requiere import)
java.io
Entrada / Salida
java.net
Comunicaciones
Sentencia de Importación: 

import java.util.Random;  // Importa la clase específica de números aleatorios
import java.util.Scanner; // Importa la clase de lectura por teclado

Paquete java.lang // Métodos de Math

La clase Math provee funciones matemáticas estáticas que no requieren instanciación (se invocan directamente como Math.metodo(...)):

Método Descripción Ejemplo en Java Resultado
Math.abs(x) Valor absoluto de un número Math.abs(-25.4) 25.4
Math.pow(x, y) Potencia de x elevado a y (xy) Math.pow(2.0, 5.0) 32.0
Math.sqrt(x) Raíz cuadrada de x Math.sqrt(144.0) 12.0
Math.ceil(x) Redondeo hacia arriba (menor entero ≥ x) Math.ceil(9.2) 10.0
Math.floor(x) Redondeo hacia abajo (mayor entero ≤ x) Math.floor(9.8) 9.0
Math.max(x, y) Retorna el mayor entre dos valores Math.max(14, 29) 29

Azar en Java // java.util.Random

En computación los números son pseudo-aleatorios: se obtienen mediante un algoritmo determinista uniforme a partir de una semilla (seed).

Generación de Rangos

rnd.nextInt(n) produce enteros en el rango [0, n - 1]. Para simular un dado de 1 a 6: rnd.nextInt(6) + 1.

Pasos de Uso en Java: 

// 1. Importar el paquete
import java.util.Random;

// 2. Crear el objeto generador
Random rnd = new Random();

// 3. Invocar métodos de azar
int dado = rnd.nextInt(6) + 1; // 1 a 6
double prob = rnd.nextDouble();  // 0.0 a 1.0

Práctica Guiada // Simulación de Dados

Paso 1: Instanciar Random

Creamos el objeto generador una única vez fuera del ciclo: Random rnd = new Random();.

Paso 2: Iterar y Escalar

El bucle for ejecuta 10 repeticiones. La fórmula rnd.nextInt(6) + 1 desplaza el rango de [0, 5] a [1, 6]. 


import java.util.Random;

public class Main {
    public static void main(String[] args) {
        Random rnd = new Random(); // Paso 1: Crear generador
        System.out.println("=== 10 TIRADAS DE UN DADO ===");
        
        for (int i = 1; i <= 10; i++) { // Paso 2: Iterar y lanzar
            int tiro = rnd.nextInt(6) + 1;
            System.out.println("Tiro #" + i + ": " + tiro);
        }
    }
}

Desafío de Azar // Doble o Mitad

Reglas del Juego:
  • El jugador inicia con un pozo (ej: 100 pesos) y lanza una moneda.
  • Cara (1): duplica su pozo actual (× 2).
  • Cruz (0): pierde la mitad (/ 2).
  • Finaliza al quedar con menos de 1 peso o tras 50 tiradas.
Lógica de Moneda: 

int moneda = rnd.nextInt(2); // 0 o 1
if (moneda == 1) {
    pozo = pozo * 2.0; // Cara: duplica
} else {
    pozo = pozo / 2.0; // Cruz: mitad
}

Módulos Base Requeridos

  • sumar(a, b): retorna la suma de ambos enteros.

  • multiplicar(a, b): retorna el producto.
