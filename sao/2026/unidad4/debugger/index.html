Guía Rápida de Pruebas de Escritorio

1. Pasaje por Valor en Tipos Primitivos (Java):
Al pasar un argumento primitivo (int, double, etc.) a un método, Java envía una copia exacta de su valor. Modificar el parámetro dentro del método jamás altera la variable original del llamador.
2. Ámbito y Ciclo de Vida (Scope):
Las variables locales y parámetros nacen cuando se invoca el método y mueren instantáneamente al llegar a la llave de cierre } o al return. Dos métodos distintos pueden tener variables con el mismo nombre sin pisarse.
3. Funciones (con Return) vs Procedimientos (void):
Un método void ejecuta una acción (como imprimir en consola), pero no produce ningún valor almacenable. Si quieres que el resultado regrese al main, la función debe usar return resultado; y el llamador debe asignarlo: x = calcular(x);.
4. El Call Stack (Pila LIFO):
Cada llamada a un método crea un marco independiente en la pila. La ejecución sólo trabaja sobre el marco activo en el tope; al retornar, ese marco se destruye y el control vuelve al marco inferior.
