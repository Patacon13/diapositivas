UNIDADES 1 & 2: Compilación, Errores y Tipos Primitivos

Flujo de Ejecución y Tipos de Error

  • Compilación portátil: .java → javac → .class (Bytecode neutro) → ejecutado por la JVM de cada sistema operativo.
  • Reglas léxicas: Java es case-sensitive; la clase public debe coincidir con el nombre del archivo; punto de entrada public static void main(String[] args).
  • Error de sintaxis: detectado por javac (falta ;, llave sin cerrar, variable local leída sin inicializar).
  • Error en ejecución (excepción): compila bien, pero aborta en JVM (división entera por cero, índice fuera de rango, tipo incompatible en Scanner).
  • Error lógico: compila y termina sin excepciones, pero entrega un resultado erróneo (ej. omitir paréntesis en a + b / 2).

Los 8 Tipos Primitivos en Java

Tipo Tamaño Rango / Detalle Clave
byte 8 bits Entero con signo: -128 a 127.
short 16 bits Entero con signo: -32.768 a 32.767.
int 32 bits Entero estándar (tipo por defecto de literales).
long 64 bits Entero largo; literales grandes exigen sufijo L.
float 32 bits Decimal simple; literal exige sufijo f.
double 64 bits Decimal doble precisión (defecto con punto decimal).
boolean 1 bit* Solo true o false (no admite 0 ni 1).
char 16 bits Un único carácter entre comillas simples ('A').
Aclaraciones de tipos, constantes y límites

String no es primitivo (es una clase/objeto con comillas dobles). Las constantes con final no pueden reasignarse. Superar el máximo o mínimo entero produce Overflow / Underflow cíclico (ej: (short)(32767 + 1) → -32768).

UNIDAD 2: Operadores, Casting y Lógica Booleana

División y Casting

  • División entera: 5 / 2 da 2 (aunque se guarde en double da 2.0).
  • Cast antes de dividir: (double) a / b da decimal; (double)(a / b) trunca antes.
  • Truncamiento: (int) 7.95 descarta decimales y resulta 7 (no redondea).
  • Dígitos y múltiplos: n % 10 extrae último dígito; n / 10 lo quita; n % k == 0 valida divisibilidad.

Precedencia y Unarios

  • Prioridad aritmética: * / % preceden a + -. Usar paréntesis ante cualquier duda.
  • Concatenación izq → der: 2 + 3 + " pts " + 4 + 1 evalúa "5 pts 41".
  • Post vs. Pre-incremento: b = a++ asigna y luego suma; c = ++a suma primero y luego asigna.
  • Operador = vs ==: = asigna valor a una variable; == compara igualdad primitiva.

Lógica y Cortocircuito

  • Negación de rangos (De Morgan): si el rango válido es x >= 0 && x <= 10, repetir entrada si x < 0 || x > 10.
  • Cortocircuito con &&: div != 0 && n % div == 0 protege contra división por cero al evaluar izquierda primero.
  • Cortocircuito con ||: si el término izquierdo es true, no evalúa el derecho.
  • Buffer Scanner: tras nextInt() queda \n; limpiar con nextLine() extra antes de leer líneas.
Cálculo de porcentajes y promedios con enteros

Si cant y total son int, escribir (cant / total) * 100.0 primero ejecuta división entera (0 si cant < total). Lo correcto es (cant * 100.0) / total o castear a (double) antes de dividir.

UNIDAD 3: Control de Flujo y Secuencias

Estructuras Selectivas (if / switch)

  • if independientes vs. if - else if: los if sueltos pueden ejecutarse todos; la cascada else if ejecuta solo la primera rama verdadera.
  • Llaves y punto y coma: sin { } el if controla solo 1 línea; un ; tras if (cond); deja el bloque siguiente suelto.
  • Tipos en switch: admite byte, short, int, char y String; prohíbe double, float y boolean.
  • Caída en cascada (fall-through): omitir break; ejecuta el case siguiente. Se aprovecha para agrupar etiquetas como case 's': case 'S':.

Bucles y Patrones de Secuencia

  • while vs. do-while: while evalúa antes (0 o más veces); do-while ejecuta al menos 1 vez (menús y validaciones) y exige ; al final.
  • for y ámbito: cantidad conocida N; la variable declarada en la cabecera solo existe dentro del bucle (y cuidado con for (...);).
  • Centinela limpio: leer el 1° dato antes del while y leer el siguiente al final del cuerpo, evitando procesar la marca de fin.
  • Extremos con negativos: inicializar min y max con el 1° dato válido del problema (nunca en 0) para mantener los valores en su universo real.
Criterio de programación estructurada en la cátedra

Evitar break para cortar bucles y nunca usar System.exit(0). Todo corte anticipado (búsqueda o menú con errores) se controla con bandera booleana y condición compuesta en el while / do-while.

UNIDAD 4: Modularización, Memoria y Bibliotecas

Diseño Modular y Contrato de Métodos

  • Principios: Top-Down (dividir en subtareas), DRY (reutilizar en vez de duplicar), Caja Negra (contrato entrada/salida) y Alta Cohesión (separar cálculo de Scanner/println).
  • Firma static: permite invocar desde main sin instanciar objetos; cada parámetro formal declara su tipo (int a, int b).
  • Retorno y void: métodos no-void exigen return en toda rama (buena práctica: variable resultado y retorno único al final). Un void no puede asignarse a variables.
  • Simplificación booleana: en vez de if (cond) return true; else return false;, retornar directo return cond;.

Call Stack, Pasaje y Paquetes Estándar

  • Call Stack (LIFO): cada invocación crea su propio marco con variables locales independientes (el último método en entrar es el primero en salir).
  • Pasaje por valor (primitivos vs. arreglos): un int se pasa por copia (no cambia en main). Un arreglo pasa copia de su referencia: mutar arr[i] modifica el original, pero arr = new int[...] solo cambia la copia local.
  • java.lang.Math (sin import): Math.pow(a, b) y Math.sqrt(x) devuelven siempre double; Math.abs, Math.max, Math.min.
  • java.util.Random (requiere import): rnd.nextInt(n) genera [0, n - 1]. Para rango [min, max]: rnd.nextInt(max - min + 1) + min.
Comunicación limpia entre módulos (sin estado global mutable)

Los datos y contadores deben viajar mediante parámetros explícitos y retornos. Descartar el valor de retorno de un método (ej. llamar a doble(x); sin asignarlo) deja sin efecto el cálculo en el invocador.

UNIDAD 5 (1/3): Vectores 1D, Memoria y Recorridos

3 Propiedades Base

Homogéneo (un solo tipo), contiguo en RAM e indexado en base 0 (0 a length - 1). Acceso en O(1).

Valores por Defecto

Al reservar con new: numéricos inician en 0 / 0.0, boolean[] en false y objetos en null.

Límites y Defensiva

arr.length es atributo (sin ()). Validar arr != null && arr.length > 0 evita excepciones de ejecución.

Lista no vacía: se puede eliminar si tope > 0.
Operación Costo Precondición Mecánica y Sentido del Bucle
Insertar al final O(1) tope < arr.length arr[tope] = val; tope++; (sin desplazamientos).
Insertar en pos O(N) tope < length y 0 <= pos <= tope Corrimiento derecha descendente: for (i = tope; i > pos; i--) arr[i] = arr[i-1];
Eliminar al final O(1) tope > 0 tope--; (la celda queda fuera del rango lógico).
Eliminar en pos O(N) tope > 0 y 0 <= pos < tope Corrimiento izquierda ascendente: for (i = pos; i < tope - 1; i++) arr[i] = arr[i+1];
Control del índice cuando se inserta o borra en recorrido

Al eliminar repetidos en un while, no incrementar i tras compactar porque un nuevo elemento ocupa la posición siguiente y debe volver a compararse. Al insertar detrás de i, avanzar i++ para saltar el valor recién insertado.

UNIDAD 5 (3/3): Matrices 2D y Vectores Paralelos

Anatomía y Dimensiones en Java

  • Arreglo de arreglos: int[][] m = new int[F][C]; siempre indexado primero por fila y luego por columna (m[fila][col]).
  • Lectura de límites: m.length devuelve cantidad de filas; m[0].length (o m[i].length) las columnas.
  • Diagonal principal: celdas donde fila y columna coinciden (m[i][i]).

Barridos y Vectores Paralelos

  • Por filas (horizontal): i afuera, j adentro → totaliza cada entidad fila (ej. servidor emisor o categoría).
  • Por columnas (vertical): j afuera, i adentro → totaliza cada columna (ej. servidor receptor o destino).
  • Cruce paralelo: el subíndice col o fila de la matriz indexa un vector paralelo (localidades[col], tarifas[s]).
Estructura Cuándo Elegirla Ejemplo Típico de Aplicación
Vector 1D (T[]) Lista homogénea con una única dimensión independiente. Notas de un curso, temperaturas horarias, tarifas de servicios.
Matriz 2D (T[][]) Tabla homogénea al cruzar dos dimensiones ortogonales (F × C). Tráfico servidor origen × destino, ventas sucursal × mes.
Vectores Paralelos Asociar atributos de distinto tipo (o metadatos) mediante el mismo índice. Vector de nombres o costos vinculado a filas o columnas de una matriz.

RESOLUCIÓN (1/4): Carga Aleatoria, Filas y Reutilización

// 1. Carga aleatoria en [0, 5] con java.util.Random
public static void cargarPrestaciones(int[][] m) {
    if (m != null) {
        Random rnd = new Random();
        for (int t = 0; t < m.length; t++) {
            for (int s = 0; s < m[t].length; s++) { m[t][s] = rnd.nextInt(6); }
        }
    }
}

// 2. Recaudación de un técnico (barrido por fila + vector paralelo)
public static int calcularRecaudacionTecnico(int[][] m, int[] tarifas, int tec) {
    int total = 0;
    if (m != null && tarifas != null && tec >= 0 && tec < m.length && m[tec].length == tarifas.length) {
        for (int s = 0; s < m[tec].length; s++) { total += m[tec][s] * tarifas[s]; }
    }
    return total;
}

// 3. Reutilización (DRY): comisión del 5% en double (evita truncamiento)
public static double calcularComision(int[][] m, int[] tarifas, int tec) {
    return calcularRecaudacionTecnico(m, tarifas, tec) * 0.05;
}
Validación defensiva y promoción numérica

Cada método verifica nulidad y límites antes de indexar y mantiene un único return. Multiplicar por 0.05 promueve el monto entero a double sin perder centavos.

RESOLUCIÓN (2/4): Servicio Estrella por Columnas

// 4. Servicio estrella: mayor cantidad total (barrido por columnas)
public static int obtenerServicioEstrella(int[][] m) {
    int estrella = -1;
    if (m != null && m.length > 0 && m[0].length > 0) {
        estrella = 0;
        int maxCant = 0;
        for (int t = 0; t < m.length; t++) { maxCant += m[t][0]; }
        for (int s = 1; s < m[0].length; s++) {
            int sumaCol = 0;
            for (int t = 0; t < m.length; t++) {
                sumaCol += m[t][s];
            }
            if (sumaCol > maxCant) {
                maxCant = sumaCol;
                estrella = s;
            }
        }
    }
    return estrella;
}
Barrido vertical por columnas

Tomamos el total real de la columna 0 (estrella = 0) como candidato inicial y comparamos desde s = 1, manteniendo todos los valores dentro del universo del problema.

RESOLUCIÓN (3/4): Filtrado a Nuevo Vector

// 5. Filtrado a nuevo vector: técnicos con comisión superior al umbral
public static int[] filtrarDestacados(int[][] m, int[] tarifas, double umbral) {
    int[] resultado = new int[0];
    if (m != null && tarifas != null && umbral > 0) {
        int cant = 0;
        for (int t = 0; t < m.length; t++) {
            if (calcularComision(m, tarifas, t) > umbral) { cant++; }
        }
        resultado = new int[cant];
        int idx = 0;
        for (int t = 0; t < m.length; t++) {
            if (calcularComision(m, tarifas, t) > umbral) {
                resultado[idx++] = t;
            }
        }
    }
    return resultado;
}
Doble pasada para dimensionar exactamente

Primero contamos cuántos técnicos cumplen para instanciar new int[cant] sin celdas sobrantes ni huecos; luego copiamos los índices reutilizando calcularComision.

RESOLUCIÓN (4/4): Menú Cíclico y Validación de Entrada

Scanner sc = new Scanner(System.in);
int[] tarifas = { 2500, 5000, 10000, 15000 };
int[][] prestaciones = new int[3][4];
cargarPrestaciones(prestaciones);
int opcion, errores = 0;

do {
    System.out.println("\n1-Recargar | 2-Total | 3-Comisiones | 4-Estrella | 5-Destacados | 0-Salir");
    opcion = sc.nextInt();
    switch (opcion) {
        case 1: cargarPrestaciones(prestaciones); break;
        case 2: /* Acumula calcularRecaudacionTecnico para cada t */ break;
        case 3: /* Imprime calcularComision(...) y busca técnico del mes */ break;
        case 4: System.out.println("Estrella: " + obtenerServicioEstrella(prestaciones)); break;
        case 5:
            double umbral;
            do { System.out.print("Umbral > 0: "); umbral = sc.nextDouble(); } while (umbral <= 0);
            System.out.println(Arrays.toString(filtrarDestacados(prestaciones, tarifas, umbral)));
            break;
        case 0: System.out.println("Fin del sistema."); break;
        default: errores++; System.out.println("Inválida (" + errores + "/3)");
    }
} while (opcion != 0 && errores < 3);
Flujo estructurado de principio a fin

El menú termina naturalmente por la condición compuesta opcion != 0 && errores < 3, y la validación del umbral aplica De Morgan (umbral <= 0) dentro de un do-while sin consumir intentos del menú.

CHECKLIST DE CÁTEDRA: Puntos Clave Antes de Programar

1. Validación Defensiva & Límites

Comprobá arr != null, longitudes válidas (0..length - 1 o < tope), rangos inf <= sup y divisores distintos de cero antes de operar.

2. Control Estructurado Limpio

Sin break en ciclos (salvo switch), sin recursión en menús, sin System.exit() y un único return al cierre de cada método.

3. Precisión Numérica y Extremos

Cuidá la división entera casteando a double antes de dividir e inicializá máximos y mínimos con el primer dato real del problema (nunca en 0) para mantener todo en su universo de valores.

4. Modularidad y Cohesión

Separar cálculo de entrada/salida, comunicar datos por parámetros y retornos, y componer funciones existentes en lugar de duplicar lógica entre opciones.
