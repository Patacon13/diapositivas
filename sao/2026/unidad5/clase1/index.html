ORGANIZACIÓN EN MEMORIA: Simples vs. Estructurados

En programación, los datos se clasifican según su arquitectura física y capacidad de almacenamiento:

Tipos Simples (Atómicos)

Ocupan una única casilla fija de memoria. Almacenan un único valor indivisible a la vez.

  • byte, short, int, long (enteros)
  • float, double (reales)
  • char (carácter ASCII/Unicode) y boolean

Tipos Estructurados (Colecciones)

Agrupan múltiples valores bajo un único identificador. Se subdividen en:

  • Estáticos: Arreglos (int[]) y matrices (int[][]). Tamaño fijo en memoria contigua.
  • Dinámicos: Listas enlazadas, colas, pilas, ArrayList y objetos String.
Foco pedagógico de la Unidad 5

Nos enfocaremos en las estructuras estáticas (vectores y matrices). Dominar la gestión de memoria y el desplazamiento de índices es la base algorítmica de toda la computación.

ANATOMÍA DEL VECTOR: Tres Propiedades Clave

Un arreglo unidimensional (vector) es una colección finita de datos que cumple rigurosamente con tres pilares fundamentales:

1. Homogéneo

Todos los elementos son estrictamente del mismo tipo de dato. Un vector de enteros sólo almacena enteros; no se pueden mezclar tipos.

2. Contiguo

Sus elementos se guardan en posiciones consecutivas de la memoria RAM, sin huecos intermedios.

3. Indexado

Cada elemento se accede de manera instantánea mediante un índice entero que inicia obligatoriamente en 0 hasta N - 1, siendo N la cantidad total de elementos.

Acceso directo en tiempo constante O(1)

Como cada casilla mide lo mismo (ej: 4 bytes para int), la computadora calcula dirección = base + (índice × tamaño) instantáneamente sin tener que recorrer los casilleros previos, siendo base la dirección en memoria del primer elemendo (índice 0).

MAPA DE MEMORIA: Índices vs. Contenido

Dado un vector int[] notas = { 70, 85, 90, 60, 75 }; de tamaño físico N = 5:

índice 0

índice 3

índice 4 (N-1)

Operación de Lectura

int x = notas[2]; → Asigna el valor 90 en x.

Operación de Escritura

notas[3] = 95; → Reemplaza el 60 por 95.

¡Alerta de Ejecución! ArrayIndexOutOfBoundsException

Intentar acceder a notas[5] o notas[-1] provocará que la Máquina Virtual Java lance una excepción y detenga el programa de inmediato.

SINTAXIS EN JAVA: Declaración e Instanciación

En Java, un vector es un objeto. Su ciclo de vida comprende la declaración y la reserva de memoria con el operador new:

// 1. Con operador new (por defecto con ceros) 
// Declaración y reserva de 10 enteros
int[] vector = new int[10];

// Usando una constante de tamaño
final int TAM = 100;
double[] mediciones = new double[TAM];

// Tamaño dinámico en tiempo de ejecución
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
int[] dinamico = new int[n];
// 2. Inicialización directa con literales 
// Se infiere el tamaño físico automáticamente
int[] pares = { 2, 4, 6, 8, 10 };

// Vector de cadenas de texto
String[] materias = { "SAO", "PBA", "AEDD" };

// Propiedad que devuelve la longitud del vector
int cantidad = pares.length; // 5 (¡sin paréntesis!)
Valores por defecto en la reserva

Al instanciar con new int[N], Java inicializa automáticamente todas las celdas numéricas en 0 (o false para booleanos y null para objetos).

RECORRIDOS EN VECTORES: Completos vs. Parciales

La estructura de control adecuada depende de si debemos procesar todo el arreglo o cortar anticipadamente:

Estrategia Casos de Uso Ideales Sintaxis Canónica
Recorrido Completo
(Todos los elementos) 		Procesar el 100% del vector:
• Sumatorias, promedios y conteos.
• Búsqueda de extremos (mínimo / máximo).
• Modificar celdas o imprimir todo.
for (int i = 0; i < arr.length; i++)
For clásico: cuando necesitás el índice o modificar.
for (int elem : arr)
For-each: lectura directa y código más limpio.
Recorrido Parcial
(Búsqueda con corte) 		Detenerse al cumplir un objetivo:
• Búsqueda de un valor determinado.
• Verificar si existe un elemento.
• Validar homogeneidad o condiciones.
int i = 0;
while (i < arr.length && arr[i] != buscado) {
    i++;
}
→ Corte por condición falsa: frena naturalmente sin recorrer casilleros innecesarios.
Regla de programación estructurada: ¡Prohibido for con break!

Si la búsqueda puede terminar antes de llegar al final del arreglo, nunca uses un for con break. En algoritmos estructurados, la detención temprana debe resolverse haciendo que la condición del while se vuelva falsa, asegurando un único punto de salida claro y predecible.

PRÁCTICA GUIADA 1: Mayor en un Rango

Problema: Escribir la función int mayor(int[] arreglo, int inf, int sup) que reciba un arreglo y dos índices de cota, retornando el valor más grande dentro del rango acotado [inf, sup].

// Algoritmo con pivote inicial en el extremo inferior 
public static int mayor(int[] arreglo, int inf, int sup) {
    // Tomamos como candidato inicial al primer elemento del rango
    int max = arreglo[inf];
    
    // Recorremos desde el siguiente casillero hasta el límite superior
    for (int i = inf + 1; i <= sup; i++) {
        if (arreglo[i] > max) {
            max = arreglo[i];
        }
    }
    return max;
}
Ejemplo de ejecución

Para A = {10, 12, 2, 0, 4, 35, 24}:
• mayor(A, 0, 3) → Retorna 12 (evalúa {10, 12, 2, 0}).
• mayor(A, 0, 6) → Retorna 35.

PRÁCTICA GUIADA 2: Verificar Homogeneidad

Problema: Escribir el método boolean todosIguales(int[] vector) que determine si todos los elementos de una colección son idénticos entre sí.

// Esquema de búsqueda de contraejemplo con bandera booleana 
    public static boolean todosIguales(int[] vector) {
        boolean respuesta=false;
        if (vector == null || vector.length <= 1) {
            respuesta=true; // Un vector vacío o de 1 elemento es homogéneo
        } else {         // Comparamos cada elemento contra el primero
            int primero = vector[0], i = 0;
            while (i < vector.length && primero == vector[i]) {
                i++;
            }
            System.out.println("Cortó en el recorrido número: " + i);
            if (i == vector.length) {
                respuesta=true;
            } 
        }
        return respuesta;
    }
Eficiencia algorítmica: Mejor Caso vs. Peor Caso

• Mejor caso O(1): El segundo elemento ya es diferente (ej: [1, 9, 1, 1]), el método retorna en la primera vuelta.
• Peor caso O(N): Todos son iguales o la diferencia está al final; requiere recorrer los N elementos.

PRÁCTICA GUIADA 3: Rotación de Vectores

Desafío: Desplazar circularmente los valores sin perder datos:

Rotar a la Izquierda

El valor de la posición 0 pasa al último casillero.
[1, 2, 3, 4] → [2, 3, 4, 1] 

int aux = arr[0]; // Salvamos el 1ro
for (int i = 0; i < arr.length - 1; i++) {
    arr[i] = arr[i + 1]; // Corremos izq
}
arr[arr.length - 1] = aux; // Restauramos

Rotar a la Derecha

El último valor pasa a la posición inicial 0.
[1, 2, 3, 4] → [4, 1, 2, 3] 

int aux = arr[arr.length - 1]; // Salvamos
for (int i = arr.length - 1; i > 0; i--) {
    arr[i] = arr[i - 1]; // Corremos der
}
arr[0] = aux; // Restauramos
La variable auxiliar es imprescindible

Si intentamos desplazar directamente sin respaldar arr[0] o el último valor, el dato se sobreescribirá y quedará destruido permanentemente.

CHECKLIST DE CÁTEDRA: Vectores Seguros

1. Límites Estrictos

El último elemento es siempre length - 1. El error más común es usar i <= length en el bucle, lo que causa desbordamiento.

2. Dirección del Desplazamiento

Al mover elementos a la derecha, el recorrido del bucle debe ser descendente (i--). Si se recorre hacia adelante, se duplica el primer valor en todas las celdas.

Pautas para la ejercitación en OmegaUp

Validá siempre que los arreglos recibidos como parámetro no sean nulos y posean una longitud válida antes de ingresar a los algoritmos de ordenamiento o corrimiento.
