DE VECTORES A MATRICES: La Dimensión Fila-Columna

Un vector representa una fila o columna unidimensional. Al cruzar dos dimensiones independientes obtenemos una matriz (arreglo bidimensional):

Planillas y Sucursales

Modelar las ventas de 12 meses (filas) en 4 sucursales distintas (columnas). Cada celda es ventas[mes][sucursal].

Registro Académico

Calificaciones de N alumnos (filas) en 3 materias como SAO, MEL y MSO (columnas) para promedios por estudiante o materia.

Redes y Servidores

Mapear el flujo de datos entre 5 servidores. red[i][j] representa los KB enviados del servidor i al j.

En Java, una matriz es un "arreglo de arreglos"

Físicamente, cada fila es un vector independiente en memoria y la matriz almacena referencias a dichos vectores de fila.

SINTAXIS EN JAVA: Declaración, Creación y Acceso

Para declarar e instanciar una matriz se emplean dobles corchetes [filas][columnas]:

// Declaración y reserva con new 
// Matriz de 3 filas x 4 columnas
int[][] matriz = new int[3][4];

// Lectura de dimensiones físicas
int totalFilas = matriz.length;       // 3
int totalCols  = matriz[0].length;    // 4

// Asignación directa en celda específica
matriz[0][0] = 15; // Fila 0, Columna 0
matriz[2][3] = 99; // Fila 2, Columna 3
// Inicialización literal (filas delimitadas) 
int[][] tablero = {
    { 10, 20, 30 }, // Fila 0
    { 40, 50, 60 }, // Fila 1
    { 70, 80, 90 }  // Fila 2
};

// Acceso al centro de la matriz
int centro = tablero[1][1]; // 50
El orden de los subíndices es sagrado

Siempre especificamos primero la fila y luego la columna: matriz[fila][columna]. Invertir el orden causará lecturas erróneas o desbordamientos fuera de rango.

Representación gráfica de una matriz int[3][4] con sus coordenadas de acceso:

Fila fija (Horizontal)

En la fila 0: [0][0], [0][1], [0][2], [0][3].

Columna fija (Vertical)

En la columna 1: [0][1], [1][1], [2][1].

ESQUEMAS DE RECORRIDO: Por Filas vs. Por Columnas

El orden de los bucles anidados define cómo se barren los datos de la matriz:

1. Recorrido por Filas (Horizontal) 
// i fija la fila, j recorre columnas
for (int i = 0; i < filas; i++) {
    int sumaFila = 0;
    for (int j = 0; j < cols; j++) {
        sumaFila += matriz[i][j];
    }
    System.out.println("Fila " + i + ": " + sumaFila);
}

Aplicación: Total por sucursal, promedio de notas por alumno.

2. Recorrido por Columnas (Vertical) 
// j fija la columna, i recorre filas
for (int j = 0; j < cols; j++) {
    int sumaCol = 0;
    for (int i = 0; i < filas; i++) {
        sumaCol += matriz[i][j];
    }
    System.out.println("Columna " + j + ": " + sumaCol);
}

Aplicación: Ventas de un mes entre sucursales, promedio por materia.

¿Cuál ciclo debe ir afuera?

El ciclo exterior es el que se mantiene fijo mientras el interior barre sus elementos. Para procesar alumno por alumno (filas), i va afuera. Para procesar materia por materia (columnas), j va afuera.

PRÁCTICA GUIADA 1: Tráfico entre Servidores (5x5)

Consigna del Problema

En un centro de datos, 5 servidores (identificados de 0 a 4) registran su intercambio de información en una matriz int[][] correo = new int[5][5];. La celda correo[i][j] representa los KB enviados desde el servidor emisor i hacia el servidor receptor j.

a) Total por Emisor

Calcular e imprimir el total de KB que envió cada servidor hacia la red (sumatoria por cada fila i).

b) Emisor Líder

Determinar cuál servidor fue el que envió la mayor cantidad de KB en total y el volumen máximo alcanzado.

c) Recepción Crítica

Informar qué servidores recibieron un tráfico total mayor a una cota cotaM = 250 KB (sumatoria por columnas j).

La diagonal principal: correo[i][i]

Representa el tráfico local de loopback que un servidor se envía a sí mismo (habitualmente 0).

Estrategia de barrido:

¿Cuál índice debe gobernar el bucle exterior para totalizar envíos (inciso a) y cuál para recepciones (inciso c)?

PRÁCTICA GUIADA 1: Resolución Paso a Paso

Implementación en Java diferenciando el recorrido por filas (envíos) del recorrido por columnas (recepciones): 

// 1. Inicialización de variables de seguimiento
int maxEnvio = -1, servMayor = -1;
int cotaM = 250;

// 2. a) y b) Total enviado por cada servidor y búsqueda de líder (POR FILAS)
for (int i = 0; i < 5; i++) {
    int totalEnviado = 0;
    for (int j = 0; j < 5; j++) {
        totalEnviado += correo[i][j];
    }
    System.out.println("Servidor " + i + " envió: " + totalEnviado + " KB");
    if (totalEnviado > maxEnvio) {
        maxEnvio = totalEnviado;
        servMayor = i;
    }
}

// 3. c) Servidores cuya recepción acumulada supera la cota M (POR COLUMNAS)
for (int j = 0; j < 5; j++) {
    int totalRecibido = 0;
    for (int i = 0; i < 5; i++) {
        totalRecibido += correo[i][j];
    }
    if (totalRecibido > cotaM) {
        System.out.println("Servidor " + j + " superó la cota con " + totalRecibido + " KB");
    }
}
La clave algorítmica:

Para evaluar a un servidor emisor dejamos fija la fila i en el bucle externo y sumamos sus columnas j. Para evaluar a un receptor, fijamos la columna j en el exterior y sumamos sus filas i.

PRÁCTICA GUIADA 2: Matrices & Vectores Paralelos

Consigna del Problema

Una aerolínea administra la venta de pasajes con una matriz pasajes[4][5] (4 categorías de servicio × 5 destinos turísticos) y un vector paralelo de nombres String[] localidades = { "Paraná", "Esquel", "Bariloche", "Ushuaia", "Iguazú" };.

1. Total por Destino

Calcular e informar la cantidad total de pasajeros que volaron a cada localidad (sumatoria por columnas).

2. Destino Menor

Determinar la localidad con menor cantidad de pasajes y mostrar su nombre cruzando el índice con localidades.

3. Categoría Vacía

Verificar si existe alguna categoría de tarifa que no haya registrado ninguna venta (sumatoria por filas == 0).

Mapeo Paralelo por Subíndice Col:
Col 0 → Paraná Col 1 → Esquel Col 2 → Bariloche Col 3 → Ushuaia Col 4 → Iguazú
¿Por qué conservar el índice col?

Guardar idxMenorDestino permite acceder a localidades[idxMenorDestino] sin perder la asociación con la columna.

PRÁCTICA GUIADA 2: Resolución Paso a Paso

Implementación en Java integrando el barrido por columnas con el vector paralelo y el barrido por filas: 

// 1. Dimensiones y variables de seguimiento
int categorias = pasajes.length;     // 4 filas
int destinos = localidades.length;    // 5 columnas
int minPasajeros = Integer.MAX_VALUE;
int idxMenorDestino = 0;

// 2. Requerimiento 1 y 2: Total por columnas (destino) y búsqueda de mínimo
for (int col = 0; col < destinos; col++) {
    int totalLoc = 0;
    for (int fila = 0; fila < categorias; fila++) {
        totalLoc += pasajes[fila][col];
    }
    System.out.println(localidades[col] + ": " + totalLoc + " pasajeros.");
    if (totalLoc < minPasajeros) {
        minPasajeros = totalLoc;
        idxMenorDestino = col; // Guardamos el índice para cruzar con el vector paralelo
    }
}

// 3. Cruce con el vector paralelo
System.out.println("Destino menos visitado: " + localidades[idxMenorDestino]);

// 4. Requerimiento 3: Total por filas para detectar categorías sin ventas
for (int fila = 0; fila < categorias; fila++) {
    int totalCat = 0;
    for (int col = 0; col < destinos; col++) {
        totalCat += pasajes[fila][col];
    }
    if (totalCat == 0) {
        System.out.println("La Categoría #" + fila + " no vendió ningún pasaje.");
    }
}
La potencia de los vectores paralelos

El subíndice de la columna en la matriz (col) se utiliza directamente como índice en el vector de nombres (localidades[col]), vinculando números con entidades del mundo real.

MAPA DE DECISIÓN: ¿Qué Estructura Elegir?

Vector Simple 1D

Usalo cuando los datos correspondan a una secuencia lineal de entidades (ej: lista de notas, secuencia de sensores, cola de espera).

Matriz 2D

Usala cuando la información dependa de dos variables ortogonales (ej: alumno × materia, mes × sucursal, coordenadas de un tablero).

Vectores Paralelos

Usalos cuando necesites asociar datos de distinto tipo (ej: vector de String con nombres y vector de int con edades) compartiendo el mismo índice.
