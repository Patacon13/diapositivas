Archivo de Alumnado Comprometido

Un hacker corrompió los registros estudiantiles dejando una matriz de 1450 × 30 caracteres (MatrizRota). Cada fila contiene Nombre, Apellido y Año de ingreso de un alumno bajo tres alteraciones clave:

Espacios Aleatorios

Se insertaron espacios en blanco aleatorios entre los caracteres que deben descartarse.

Separador '$'

Los caracteres previos al $ forman el Nombre y los posteriores el Apellido.

4 Dígitos Invertidos

Los 4 dígitos del año de ingreso vienen invertidos en su orden de aparición.

EJEMPLO DE RECONSTRUCCIÓN:
Fila[0]: E 5v a0r is0 2t o$ P o rt el a → Reconstruido: Portela Evaristo 2005
a

Alumno y ReconstruyeLinea()

Defina las estructuras de datos necesarias y codifique la función ReconstruyeLinea():

  • struct Alumno: campos nombre (string), apellido (string) y anioIngreso (int).
  • La función recibe una fila de la matriz (30 caracteres) y retorna un Alumno con su información original.
  • Elimina espacios en blanco redundantes y separa nombre y apellido según el delimitador $.
  • Invierte los 4 dígitos dispersos para recomponer el año real. (NO modificar MatrizRota).

Lógica de Inversión: Si los dígitos leídos son '5','0','0','2', se operan de atrás hacia adelante: anio = anio * 10 + (c - '0') obteniendo 2005.

a

Solución: ReconstruyeLinea()


struct Alumno {
    string nombre;
    string apellido;
    int anioIngreso;
};

Alumno ReconstruyeLinea(const char fila[ANCHO_FILA]) {
    Alumno alu;
    alu.nombre = ""; alu.apellido = ""; alu.anioIngreso = 0;
    char digitos[4];
    int cantDigitos = 0;
    bool pasoSeparador = false;

    for (int j = 0; j < ANCHO_FILA; j++) {
        char c = fila[j];
        if (c == '$') {
            pasoSeparador = true;
        } else if (c >= '0' && c <= '9') {
            if (cantDigitos < 4) {
                digitos[cantDigitos] = c;
                cantDigitos++;
            }
        } else if (c != ' ' && c != '\0') {
            if (!pasoSeparador) {
                alu.nombre += c;
            } else {
                alu.apellido += c;
            }
        }
    }

    int anio = 0;
    for (int k = cantDigitos - 1; k >= 0; k--) {
        anio = anio * 10 + (digitos[k] - '0');
    }
    alu.anioIngreso = anio;
    return alu;
}

ListaAlumnos y ReconstruyeInfo()

Defina el struct ListaAlumnos y codifique la función ReconstruyeInfo():

  • struct ListaAlumnos: arreglo lista[1450] y tamaño lógico tl.
  • La función recibe la MatrizRota y retorna la información original procesada en un dato de tipo ListaAlumnos.
  • Filtro de Seguridad: Las filas corruptas que contienen la subcadena DANGER son irrecuperables y no deben incluirse en el vector reconstruido.

Modularización AEDD: Extraemos la verificación de la subcadena a una función auxiliar contieneDanger() con bandera lógica, garantizando retorno único sin sentencias break.

b

Solución: ReconstruyeInfo()


struct ListaAlumnos {
    Alumno lista[MAX_ALUMNOS];
    int tl;
};

bool contieneDanger(const char fila[ANCHO_FILA]) {
    const string patron = "DANGER";
    bool encontrado = false;
    int i = 0;
    while (i <= ANCHO_FILA - 6 && !encontrado) {
        bool coincide = true;
        int k = 0;
        while (k < 6 && coincide) {
            if (fila[i + k] != patron[k]) {
                coincide = false;
            }
            k++;
        }
        if (coincide) { encontrado = true; }
        i++;
    }
    return encontrado;
}

ListaAlumnos ReconstruyeInfo(const char matriz[MAX_ALUMNOS][ANCHO_FILA]) {
    ListaAlumnos resultado;
    resultado.tl = 0;

    for (int i = 0; i < MAX_ALUMNOS; i++) {
        if (!contieneDanger(matriz[i])) {
            resultado.lista[resultado.tl] = ReconstruyeLinea(matriz[i]);
            resultado.tl++;
        }
    }
    return resultado;
}

TDA PilaAlumnos y Complejidad O(1)

Para operaciones bajo política LIFO sobre arreglos estáticos:

  • Defina PilaAlumnos con vector de capacidad 1450 y subíndice tope.
  • c.1) Codifique las 5 primitivas fundamentales: inicializarPila, pilaVacia, pilaLlena, apilar (control overflow) y desapilar (control underflow).
  • c.2) Indique y justifique formalmente la complejidad temporal algorítmica Big-O de apilar() y desapilar().

Complejidad O(1) Ambas primitivas operan en tiempo constante: acceden directamente por índice (elementos[tope]) e incrementan/decrementan el tope sin realizar desplazamientos en memoria.

c

Solución: TDA PilaAlumnos


struct PilaAlumnos {
    Alumno elementos[MAX_PILA];
    int tope; // -1 indica pila vacía
};

void inicializarPila(PilaAlumnos &p) { p.tope = -1; }
bool pilaVacia(const PilaAlumnos &p) { return (p.tope == -1); }
bool pilaLlena(const PilaAlumnos &p) { return (p.tope == MAX_PILA - 1); }

bool apilar(PilaAlumnos &p, Alumno alu) {
    bool pudo = false;
    if (!pilaLlena(p)) {
        p.tope++;
        p.elementos[p.tope] = alu;
        pudo = true;
    }
    return pudo;
}

bool desapilar(PilaAlumnos &p, Alumno &alu) {
    bool pudo = false;
    if (!pilaVacia(p)) {
        alu = p.elementos[p.tope];
        p.tope--;
        pudo = true;
    }
    return pudo;
}

auditarAlumnos() y Complejidad Total

Codifique auditarAlumnos() recibiendo ListaAlumnos y dos pilas (pilaHistoricos y pilaRecientes):

  • Uso exclusivo de primitivas: apilar en pilaHistoricos si anioIngreso ≤ 2010, o en pilaRecientes si es posterior.
  • Desapilar sucesivamente todos los elementos de pilaHistoricos contabilizando y mostrando los alumnos cuyo apellido tenga más de 8 caracteres.
  • Determinar y justificar formalmente la complejidad temporal total en función de $N$.

Complejidad Total O(N) Recorrido de la lista: N × O(1) = O(N). Desapilado de históricos (K ≤ N): K × O(1) ≤ O(N). Total: O(N) + O(N) = O(N) (lineal).

d

Solución: auditarAlumnos()


void auditarAlumnos(const ListaAlumnos &listaAlumnos, 
                    PilaAlumnos &pilaHistoricos, 
                    PilaAlumnos &pilaRecientes) {
    inicializarPila(pilaHistoricos);
    inicializarPila(pilaRecientes);

    for (int i = 0; i < listaAlumnos.tl; i++) {
        if (listaAlumnos.lista[i].anioIngreso <= 2010) {
            apilar(pilaHistoricos, listaAlumnos.lista[i]);
        } else {
            apilar(pilaRecientes, listaAlumnos.lista[i]);
        }
    }

    int cantApellidoLargo = 0;
    Alumno aluActual;

    while (desapilar(pilaHistoricos, aluActual)) {
        if (aluActual.apellido.length() > 8) {
            cantApellidoLargo++;
            cout << "• " << aluActual.apellido << ", " << aluActual.nombre 
                 << " (Ingreso: " << aluActual.anioIngreso << ")" << endl;
        }
    }
    cout << "Total de historicos con apellido largo: " 
         << cantApellidoLargo << endl;
}
