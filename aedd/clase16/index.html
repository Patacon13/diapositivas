Sistema de Guardia Médica y Triage

Guardia Médica UTN FRSF

El sistema gestiona la recepción y atención de pacientes mediante colas circulares sobre arreglos estáticos siguiendo el modelo de cátedra (subíndices Primero y Ultimo, sin contador de cantidad), garantizando tiempos acotados de respuesta en $O(1)$.

Código Rojo (0)

Emergencia Crítica

Cola de prioridad máxima. Atención inmediata ante cualquier arribo.

Código Amarillo (1)

Urgencia Moderada

Se atiende cuando la cola de Código Rojo se encuentra vacía.

Código Verde (2)

Consulta Ambulatoria

Atención cuando ambas colas anteriores se encuentren vacías.

Capacidades: Arreglo circular de 40 posiciones (MAX_COLA = 40). Al reservar 1 lugar de control, aloja hasta 39 pacientes útiles. El historial AtencionesRealizadas almacena hasta 300 registros.

a

Tipos y función main()

Defina todos los tipos de datos y estructuras necesarias en C++ para representar:

  • Paciente: dni (long long), nombre (string), prioridad (0 a 2), minutoLlegada (0 a 1439).
  • Cola: implementada sobre un arreglo circular con subíndices Primero y Ultimo según el modelo de teoría (máx. 39 pacientes en vector de 40).
  • Atencion: registro del paciente y su minutoAtencion efectivo.

Luego, codifique la función main() declarando el arreglo de las 3 colas (adecuadamente inicializadas como vacías con Primero = Ultimo = 0) y el vector AtencionesRealizadas (máx. 300) con su respectivo tamaño lógico en cero.

a

Solución: Tipos y main()


#include <iostream>
#include <string>
using namespace std;

const int PRIORIDADES = 3;
const int MAX_COLA = 40;
const int MAX_ATENCIONES = 300;

struct Paciente {
    long long dni;
    string nombre;
    int prioridad;      // 0: Rojo, 1: Amarillo, 2: Verde
    int minutoLlegada;  // 0 a 1439
};

struct Cola {
    Paciente info[MAX_COLA];
    int Primero;
    int Ultimo;
};

struct Atencion {
    Paciente paciente;
    int minutoAtencion;
};

void inicializarCola(Cola &c) {
    c.Primero = 0;
    c.Ultimo = 0;
}

int main() {
    Cola colasPrioridad[PRIORIDADES];
    for (int i = 0; i < PRIORIDADES; i++) {
        inicializarCola(colasPrioridad[i]);
    }

    Atencion atencionesRealizadas[MAX_ATENCIONES];
    int cantAtenciones = 0;

    return 0;
}

Función encolarPaciente()

Diseñe y codifique la función encolarPaciente() respetando el principio FIFO y la convención de teoría de cola circular.

  • La función debe recibir la cola correspondiente y los datos del paciente a ingresar.
  • Si la cola se encuentra llena, no debe alterarla y debe retornar false.
  • Si dispone de lugar, debe insertar al paciente en la posición Ultimo, avanzar y retornar true.
b

Solución: encolarPaciente()

Convención de Teoría: Control de cola llena con (c.Ultimo + 1) % MAX_COLA == c.Primero. Se inserta en c.info[c.Ultimo] y avanza con aritmética modular. 


bool encolarPaciente(Cola &c, Paciente p) {
    bool pudoEncolar = false;

    if ((c.Ultimo + 1) % MAX_COLA != c.Primero) {
        c.info[c.Ultimo] = p;
        c.Ultimo = (c.Ultimo + 1) % MAX_COLA;
        pudoEncolar = true;
    }

    return pudoEncolar;
}

Función atenderSiguiente()

Codifique la función atenderSiguiente() que recibe el arreglo de las 3 colas de prioridad, el vector AtencionesRealizadas (con su tamaño lógico) y el minutoActual de atención:

  • Despacha al siguiente paciente respetando el orden estricto de triage: Rojo (0) → Amarillo (1) → Verde (2).
  • Si las 3 colas están vacías (Primero == Ultimo en todas), informa un aviso y no modifica el historial.
  • El paciente atendido se retira de su cola avanzando Primero con aritmética modular y se inserta al final de AtencionesRealizadas registrando su minutoAtencion e incrementando su tamaño lógico.
c

Solución: atenderSiguiente()


// Funciones auxiliares modulares
bool colaVacia(const Cola &c) {
    return (c.Primero == c.Ultimo);
}

bool desencolarPaciente(Cola &c, Paciente &p) {
    bool pudo = false;
    if (!colaVacia(c)) {
        p = c.info[c.Primero];
        c.Primero = (c.Primero + 1) % MAX_COLA;
        pudo = true;
    }
    return pudo;
}

void atenderSiguiente(Cola colas[], Atencion atenciones[],
                      int &cantAtenciones, int minutoActual) {
    int prioridadElegida = -1;
    int i = 0;
    bool encontrado = false;

    // Seleccionar la cola de mayor urgencia que no este vacia
    while (i < PRIORIDADES && !encontrado) {
        if (!colaVacia(colas[i])) {
            prioridadElegida = i;
            encontrado = true;
        }
        i++;
    }

    if (prioridadElegida == -1) {
        cout << "Aviso: No hay pacientes en espera en ninguna cola." << endl;
    } else {
        if (cantAtenciones < MAX_ATENCIONES) {
            Paciente p;
            desencolarPaciente(colas[prioridadElegida], p);

            atenciones[cantAtenciones].paciente = p;
            atenciones[cantAtenciones].minutoAtencion = minutoActual;
            cantAtenciones++;
        } else {
            cout << "Aviso: Registro historico de atenciones lleno." << endl;
        }
    }
}

Espera Crítica (Recursiva)

Con el objetivo de analizar la demora en la guardia, el tiempo de espera de un paciente atendido se calcula como:

espera = minutoAtencion - minutoLlegada

Codifique una función recursiva pacientesConEsperaCritica() que reciba el vector de AtencionesRealizadas, su tamaño lógico y un entero limiteMinutos.

  • Debe retornar la cantidad de pacientes del historial cuyo tiempo de espera haya superado el limiteMinutos estipulado.
  • Restricción: Implementación estrictamente recursiva sin bucles for ni while.
d

Solución: pacientesConEsperaCritica()

Caso Base: n == 0 retorna 0.
Paso Recursivo: Evalúa la última posición (n - 1) y acumula el conteo llamando a la función con tamaño n - 1. 


int pacientesConEsperaCritica(const Atencion atenciones[], int n, int limiteMinutos) {
    int total = 0;

    if (n > 0) {
        int espera = atenciones[n - 1].minutoAtencion 
                   - atenciones[n - 1].paciente.minutoLlegada;
        int sumaActual = 0;
        if (espera > limiteMinutos) {
            sumaActual = 1;
        }
        total = sumaActual + pacientesConEsperaCritica(atenciones, n - 1, limiteMinutos);
    }

    return total;
}
