Concepto de Matriz (2D)

Una matriz es un arreglo bidimensional. Se puede imaginar como una cuadrícula o tabla compuesta por filas (horizontal) y columnas (vertical).

Puntos Clave:

  • Se declaran: int matriz[FILAS][COL];
  • Los índices comienzan en 0.
  • Se utilizan bucles anidados (normalmente `for` o `while`) para recorrerlas.

Ejercicio 6 - Sopa de Letras

Se recibe una matriz SopaLetras (orden 10 x 10) de caracteres y una palabra P almacenada en una cadena de caracteres de longitud máxima 10. Se debe informar:

  • Si esa palabra se encuentra en alguna fila, de derecha a izquierda. (Si se la encuentra indicarlo con un mensaje del tipo: la palabra XXXX está en la fila NN).
  • Cuántas columnas tienen únicamente letras minúsculas.

Nota: Si la palabra tiene menos de 10 caracteres (por ejemplo 6), se considera que está en una fila si la palabra aparece ocupando las últimas seis posiciones y todas las restantes son blancos.

Solución: Sopa de Letras


bool buscarDerechaAIzquierda(char sopa[10][10], string P) {
    bool encontradaGlobal = false;
    int fila = 0;
    while (fila < 10 && !encontradaGlobal) {
        bool coinciden = true;
        int pLen = P.length();
        int jSopa = 9;
        int iP = pLen - 1;
        while (coinciden && jSopa >= 0) {
            if (iP >= 0) {
                if (sopa[fila][jSopa] != P[iP]) coinciden = false;
                iP--;
            } else {
                if (sopa[fila][jSopa] != ' ') coinciden = false;
            }
            jSopa--;
        }
        if (coinciden) encontradaGlobal = true;
        fila++;
    }
    return encontradaGlobal;
}

int columnasMinusculas(char sopa[10][10]) {
    int cantidad = 0;
    for (int col = 0; col < 10; col++) {
        bool soloMinusculas = true;
        int fila = 0;
        while (fila < 10 && soloMinusculas) {
            char c = sopa[fila][col];
            if ((c < 'a' || c > 'z') && c != ' ') soloMinusculas = false;
            fila++;
        }
        if (soloMinusculas) cantidad++;
    }
    return cantidad;
}

OmegaUp - Cuad. Semimágicos

Un cuadrado semimágico es una matriz `N x N` donde la suma de cada fila, cada columna y ambas diagonales vale lo mismo.

Imprimir 1 si la matriz cumple, o 0 en caso contrario.

https://omegaup.com/arena/problem/Los-cuadrados-semimagicos

    bool esMagico = true;

        if (sumaCol != sumObjetivo) esMagico = false;
        j++;

    // Diagonales
    if (esMagico) {
        int sumaDiag1 = 0;
        for (int k = 0; k < n; k++) sumaDiag1 += matriz[k][k];
        if (sumaDiag1 != sumObjetivo) esMagico = false;

OmegaUp - Matriz y Vector

Dado un Vector de `T` elementos (ordenado) y una Matriz `T x T`, procesar:

  • Q=1: Mostrar cantidad de filas ordenadas de la misma forma que el vector.
  • Q=2: Mostrar primer valor de cada columna que sea mayor al promedio del vector (o -1 si no existe).

https://omegaup.com/arena/problem/MatrizyVector/

Solución: Matriz y Vector


int FilasOrdenadas(int matriz[10][10], int vector[10], int T) {
    int filasOrdenadas = 0;
    for (int i = 0; i < T; i++) {
        bool igual = true;
        int j = 0;
        while (j < T && igual) {
            if (matriz[i][j] != vector[j]) igual = false;
            j++;
        }
        if (igual) filasOrdenadas++;
    }
    return filasOrdenadas;
}

void PrimerMayorenColumna(int matriz[10][10], int vector[10], int T) {
    int suma = 0;
    for (int i = 0; i < T; i++) suma += vector[i];
    double promedio = (double)suma / T;
    
    for (int col = 0; col < T; col++) {
        bool encontrado = false;
        int fila = 0;
        int valor = -1;
        while (fila < T && !encontrado) {
            if (matriz[fila][col] > promedio) {
                valor = matriz[fila][col];
                encontrado = true;
            }
            fila++;
        }
        cout << valor << " ";
    }
    cout << endl;
}
