TDA Pila: Estructura LIFO

Last In, First Out (LIFO)

El último elemento insertado es el primero en salir. El acceso está restringido exclusivamente a un extremo llamado cima o tope.

Lista Enlazada Restringida

Cada nodo apunta al elemento inmediatamente inferior. El fondo de la pila se identifica porque su enlace apunta a NULL.

Operaciones Primitivas

apilar(P, x): inserta en el tope.
desapilar(P, x): extrae del tope y libera el nodo.
pilaVacia(P): verifica si P == NULL.

Mecánica en Memoria: Apilar y Desapilar

Inserción (Apilar) — O(1)

  1. Reservar nodo en el Heap: nuevo = new NodoPila;
  2. Guardar dato: nuevo->info = valor;
  3. Enlazar al tope previo: nuevo->sig = P;
  4. Actualizar el tope: P = nuevo;
Orden crítico: primero apuntar nuevo->sig a P y recién después mover P = nuevo para no perder el resto de la pila.

Eliminación (Desapilar) — O(1)

  1. Controlar que no esté vacía: if (!pilaVacia(P))
  2. Rescatar valor y nodo: valor = P->info; aux = P;
  3. Avanzar el tope: P = P->sig;
  4. Liberar memoria: delete aux;
Sin fugas de memoria: siempre usar aux antes de avanzar P para poder ejecutar delete aux.

Nota de cursada (PtrNodo &P vs PtrNodo *P): En el material de teoría se utiliza puntero doble (PtrNodo *P, estilo C) invocando con &P1. En la práctica de C++ (Guía 18 en adelante) usamos pasaje por referencia (PtrNodo &P), lo que evita el operador *P dentro de cada función manteniendo exactamente el mismo efecto sobre el tope.

TDA Pila: Interfaz (pila.h)


// === pila.h ===
struct NodoPila {
    int info;
    NodoPila* sig;
};

typedef NodoPila* PtrNodo;

bool pilaVacia(PtrNodo P);
bool apilar(PtrNodo &P, int valor);
bool desapilar(PtrNodo &P, int &valor);
void mostrarPila(PtrNodo P);
void liberarPila(PtrNodo &P);
void invertirPila(PtrNodo &P);

Principio de Caja Negra

El programa cliente (main.cpp) incluye "pila.h" y manipula la pila únicamente mediante sus primitivas, sin recorrer punteros ->sig manualmente.

Complejidad Temporal

pilaVacia, apilar y desapilar: O(1).
mostrarPila, liberarPila e invertirPila: O(N).

TDA Pila: Implementación (pila.cpp)


// === pila.cpp ===
#include <iostream>
#include "pila.h"
using namespace std;

bool pilaVacia(PtrNodo P) {
    return (P == NULL);
}

bool apilar(PtrNodo &P, int valor) {
    bool exito = false;
    PtrNodo nuevo = new NodoPila;
    if (nuevo != NULL) {
        nuevo->info = valor;
        nuevo->sig = P;
        P = nuevo;
        exito = true;
    }
    return exito;
}

bool desapilar(PtrNodo &P, int &valor) {
    bool exito = false;
    if (!pilaVacia(P)) {
        PtrNodo aux = P;
        valor = P->info;
        P = P->sig;
        delete aux;
        exito = true;
    }
    return exito;
}

void liberarPila(PtrNodo &P) {
    int descarte;
    while (!pilaVacia(P)) {
        desapilar(P, descarte);
    }
}

void invertirPila(PtrNodo &P) {
    PtrNodo pAux = NULL;
    int valor;
    while (!pilaVacia(P)) {
        desapilar(P, valor);
        apilar(pAux, valor);
    }
    P = pAux;
}

TDA Cola: Estructura FIFO con 2 Punteros

First In, First Out (FIFO)

El primer elemento en entrar es el primero en salir (como una fila de atención o cola de impresión).

Dos Extremos Diferenciados

Se inserta (encola) únicamente por el final (Ultimo) y se elimina (desencola) únicamente por el frente (Primero).

¿Por qué mantener Ultimo? Sin él, cada inserción obligaría a recorrer toda la lista (O(N)). Con ambos punteros en un struct Cola, encolar y desencolar son O(1).

Casos Borde al Encolar y Desencolar

Encolar: Cola Vacía vs No Vacía

El nuevo nodo siempre se crea con nuevo->sig = NULL; porque será el último.

  • Si colaVacia(C): el nuevo nodo es también el primero: C.Primero = nuevo;
  • Si no está vacía: se encadena detrás del último: C.Ultimo->sig = nuevo;
  • Siempre al final: C.Ultimo = nuevo;

Desencolar: Último Elemento

Al extraer desde C.Primero, avanzamos C.Primero = C.Primero->sig; y liberamos temp.

Error frecuente: Si la cola tenía un único nodo, C.Primero pasa a valer NULL, pero C.Ultimo seguiría apuntando al nodo recién borrado (puntero colgante).
Solución obligatoria: if (C.Primero == NULL) C.Ultimo = NULL;

Inicialización obligatoria: Antes de operar con una variable Cola C;, sus dos punteros contienen basura de memoria. Llamar siempre a inicializarCola(C) para dejar Primero = NULL y Ultimo = NULL.

TDA Cola: Interfaz (cola.h)


// === cola.h ===
struct NodoCola {
    char info;
    NodoCola* sig;
};

typedef NodoCola* NodoPtr;

struct Cola {
    NodoPtr Primero;
    NodoPtr Ultimo;
};

void inicializarCola(Cola &C);
bool colaVacia(Cola C);
bool encolar(Cola &C, char valor);
bool desencolar(Cola &C, char &valor);
void mostrarCola(Cola C);
void liberarCola(Cola &C);

Encapsulamiento

Agrupar Primero y Ultimo dentro de struct Cola simplifica el pasaje de parámetros y evita desincronizar ambos punteros en el programa cliente.

Seguridad en desencolar

Retornar bool e informar el valor por parámetro de referencia char &valor evita leer memoria inválida si la cola está vacía.

TDA Cola: Implementación (cola.cpp)


// === cola.cpp ===
#include <iostream>
#include "cola.h"
using namespace std;

void inicializarCola(Cola &C) {
    C.Primero = NULL;
    C.Ultimo = NULL;
}

bool colaVacia(Cola C) {
    return (C.Primero == NULL);
}

bool encolar(Cola &C, char valor) {
    bool exito = false;
    NodoPtr nuevo = new NodoCola;
    if (nuevo != NULL) {
        nuevo->info = valor;
        nuevo->sig = NULL;
        if (colaVacia(C)) {
            C.Primero = nuevo;
        } else {
            C.Ultimo->sig = nuevo;
        }
        C.Ultimo = nuevo;
        exito = true;
    }
    return exito;
}

bool desencolar(Cola &C, char &valor) {
    bool exito = false;
    if (!colaVacia(C)) {
        NodoPtr temp = C.Primero;
        valor = temp->info;
        C.Primero = C.Primero->sig;
        if (C.Primero == NULL) {
            C.Ultimo = NULL;
        }
        delete temp;
        exito = true;
    }
    return exito;
}

Aplicaciones de Pilas en Compiladores

1. Símbolos Equilibrados

Validar anidamientos de ( ), [ ], { } o begin / end al leer una expresión de izquierda a derecha:

  1. Símbolo de apertura → apilar en la pila.
  2. Símbolo de cierre → si la pila está vacía, hay error; si no, desapilar y verificar que coincida el tipo.
  3. Fin de entrada → equilibrada sii pilaVacia(P).

2. Notación Postfija (Polaca Inversa)

Permite evaluar expresiones sin paréntesis ni reglas de precedencia ambiguas:

Infija: (1 - 2) - 4 ^ 5 * 3
Postfija: 1 2 - 4 5 ^ 3 * -

  • Evaluación: operando → apilar; operador → desapilar 2 operandos, operar y apilar el resultado.
  • Conversión Infija → Postfija: los operandos pasan directo a la salida; los operadores esperan en la pila.

Conversión de Infija a Postfija

1. Operando

Pasa directo a la salida.

2. Paréntesis (

Se apila directamente.

3. Paréntesis )

Desapilar a salida hasta encontrar ( y descartarlo.

4. Operador

Desapilar mayor precedencia (o igual si asoc. izq.) y apilar.

Ejemplo: Infija 1 - 2 ^ 3 ^ 3 - ( 4 + 5 * 6 ) * 7 → Postfija 1 2 3 3 ^ ^ - 4 5 6 * + 7 * -

Para pensar antes de codificar: Si detectamos un ) con la pila vacía, o si al terminar la cadena quedan ( sin cerrar, ¿qué debemos hacer con los nodos que hayan quedado en el Heap antes de retornar?

1

Resolución Paso a Paso // Balanceo


bool balanceada(string expresion) {
    PtrNodo pila = NULL;
    bool valida = true;
    unsigned i = 0;
    char descarte;

    while (i < expresion.size() && valida) {
        if (expresion[i] == '(') {
            apilar(pila, '(');
        } else if (expresion[i] == ')') {
            if (pilaVacia(pila)) {
                valida = false;
            } else {
                desapilar(pila, descarte);
            }
        }
        i = i + 1;
    }

    if (!pilaVacia(pila)) {
        valida = false;
        liberarPila(pila);
    }
    return valida;
}

Buenas prácticas AEDD: Condición compuesta en while (sin break ni return temprano), liberación garantizada con liberarPila(pila) si quedaron paréntesis abiertos y retorno único al final.

2

Cola de Impresión FIFO (Uso de TDA Cola)

Implementar un simulador de cola de impresión usando el TDA Cola (de caracteres o identificadores). El programa debe leer comandos por entrada estándar hasta ingresar F:

  • E <id>: Encola el trabajo identificado con el caracter <id>.
  • D: Desencola e imprime el trabajo más antiguo (o informa si está vacía).
  • M: Muestra los trabajos pendientes desde Primero hasta NULL.
  • F: Libera toda la memoria dinámica pendiente y finaliza.

Restricción de diseño: main() debe respetar la caja negra del TDA Cola. Solo puede invocar inicializarCola, colaVacia, encolar, desencolar, mostrarCola y liberarCola.

2

Resolución Paso a Paso // Cola FIFO


int main() {
    Cola impresora;
    char cmd, idTrabajo;
    inicializarCola(impresora);

    cin >> cmd;
    while (cmd != 'F') {
        if (cmd == 'E') {
            cin >> idTrabajo;
            encolar(impresora, idTrabajo);
        } else if (cmd == 'D') {
            if (desencolar(impresora, idTrabajo)) {
                cout << "Imprimiendo: " << idTrabajo << endl;
            } else {
                cout << "Cola vacia." << endl;
            }
        } else if (cmd == 'M') {
            mostrarCola(impresora);
        }
        cin >> cmd;
    }

    liberarCola(impresora);
    return 0;
}

Gestión limpia del Heap: Al salir del bucle con cmd == 'F', liberarCola(impresora) desencola cualquier nodo remanente y deja Primero y Ultimo en NULL.

3

Invertir los Primeros K Elementos de una Cola

Dada una Cola C con N enteros y un entero K (0 <= K <= N), escribir una función invertirPrimerosK(Cola &C, int k, int n) que invierta únicamente el orden de los primeros K elementos, conservando el orden relativo de los N - K restantes.

Ejemplo con N = 5, K = 3:

Entrada: [10, 20, 30, 40, 50]
Salida: [30, 20, 10, 40, 50]

Estrategia combinada (Pila + Cola): (1) Desencolar K elementos y apilarlos en una Pila auxiliar; (2) desapilarlos y re-encolarlos al final de C; (3) rotar los N - K elementos restantes desencolando y volviendo a encolar.

3

Resolución Paso a Paso // Pila + Cola


void invertirPrimerosK(Cola &C, int k, int n) {
    PtrNodo pilaAux = NULL;
    int val, i;

    for (i = 0; i < k; i = i + 1) {
        if (desencolar(C, val)) {
            apilar(pilaAux, val);
        }
    }

    while (!pilaVacia(pilaAux)) {
        desapilar(pilaAux, val);
        encolar(C, val);
    }

    for (i = 0; i < n - k; i = i + 1) {
        if (desencolar(C, val)) {
            encolar(C, val);
        }
    }
}

Análisis de complejidad: Cada elemento se encola, apila o rota a lo sumo una cantidad constante de veces. El algoritmo opera en O(N) tiempo y O(K) espacio auxiliar, sin romper la caja negra de ningún TDA.
