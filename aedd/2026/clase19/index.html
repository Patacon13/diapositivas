Archivos de Texto vs Archivos Binarios

Archivos de Texto

  • Almacenan caracteres legibles (ASCII / UTF-8).
  • Líneas de longitud variable delimitadas por \n.
  • Requieren parsing y conversiones costosas (ej. convertir texto "12345" a int).
  • Lectura estrictamente secuencial: Para llegar a la línea 1000 hay que leer las 999 anteriores.

Archivos Binarios

  • Copia exacta de los bytes de la memoria RAM al disco (sin transformar).
  • Registros con tamaño fijo y predecible (sizeof(Registro)).
  • Máxima velocidad de E/S y menor ocupación de almacenamiento.
  • Acceso Aleatorio en O(1): Saltamos directamente a cualquier registro calculando su byte offset.

Manejo de Cadenas y Memoria en Binarios


// ERROR CRITICO: Contiene puntero dinamico
struct PersonaInvalida {
    string nombre; // Almacena puntero al Heap!
    int edad;
};

// CORRECTO: Estructura de tamanio fijo
struct PersonaArchivo {
    char nombre[50]; // 50 bytes contiguos
    int edad;        // 4 bytes
};

// Copia segura de string a char[]
void copiarCadena(char dest[], int maxLen, const string& src) {
    strncpy(dest, src.c_str(), maxLen - 1);
    dest[maxLen - 1] = '\0'; // Garantizar terminador
}

¿Por qué std::string causa error de memoria?

std::string no almacena los caracteres en el cuerpo de la variable, sino un puntero dinámico a la memoria RAM. Al hacer write, se graba en disco la dirección del puntero, no el texto. Al reabrir el archivo, esa dirección apunta a memoria inválida.

Requisito de Estructuras

Toda estructura que se persista en un archivo binario debe ser de tamaño fijo y plano (Plain Old Data): tipos primitivos y arreglos char[].

Operaciones Primitivas: read() y write()

Escritura en Bloque: write()

Copia N bytes desde la dirección de memoria hacia el disco.


ofstream arch("inventario.dat", 
              ios::binary | ios::out | ios::app);

Libro l;
// Carga de campos...

// write((char*)&var, sizeof(var))
arch.write((char*)&l, sizeof(Libro));

if (!arch) {
    cout << "Error al escribir registro" << endl;
}
arch.close();

Lectura en Bloque: read()

Lee N bytes desde el disco y los vuelca en la memoria.


ifstream arch("inventario.dat", 
              ios::binary | ios::in);

Libro l;

// Lectura secuencial registro a registro
while (arch.read((char*)&l, sizeof(Libro))) {
    cout << "Titulo: " << l.titulo 
         << " | Precio: ARS " << l.precio << endl;
}

arch.close();

Acceso Aleatorio: seekg, seekp y tell

Punteros de Flujo en C++

get pointer (lectura): seekg(offset, origen) / tellg()
put pointer (escritura): seekp(offset, origen) / tellp()

Puntos de Referencia (Origen)

ios::beg: Relativo al inicio del archivo (byte 0).
ios::cur: Relativo a la posición actual del cursor.
ios::end: Relativo al final del archivo (EOF).

Fórmula del Offset de Byte (1-Indexed)

int offset = (k - 1) * sizeof(Registro);

El 1er registro está en 0 bytes. El 3er registro (k=3) con sizeof=128 está en el byte (3-1)*128 = 256. 


// Saltar directamente al registro 3 en O(1)
int pos = 3;
int offset = (pos - 1) * sizeof(Libro);

arch.seekg(offset, ios::beg); // Salto exacto
arch.read((char*)&l, sizeof(Libro));

Cálculo del Total de Registros en Disco


int obtenerCantidadRegistros(const string& ruta) {
    ifstream arch(ruta, ios::binary | ios::in);
    if (!arch) return 0;

    // 1. Desplazar cursor al final del archivo
    arch.seekg(0, ios::end);

    // 2. tellg() devuelve el tamanio total en bytes
    int totalBytes = arch.tellg();

    // 3. Division exacta por el tamanio de registro
    int cantidad = totalBytes / sizeof(Libro);

    arch.close();
    return cantidad;
}

Carga y Creación de Archivo Binario (Guía Ej 5)

Guía de Archivos — Ejercicio 5: Escribir un programa que permita cargar desde teclado registros que contengan los siguientes campos:

• Título del libro (hasta 50 caracteres)
• Autor (hasta 40 caracteres)
• ISBN (hasta 20 caracteres)
• Precio (real)
• Cantidad en existencia (entero)
• Cantidad vendida (entero)

Guardar esta información en un archivo binario de "inventario.dat" en modo adición.

Clave de Diseño

Usar ios::binary | ios::out | ios::app para preservar los libros existentes al agregar nuevos registros al final del archivo.

1

Solución: Carga Binaria en C++


struct Libro {
    char titulo[50];
    char autor[40];
    char isbn[20];
    float precio;
    int stock;
    int ventas;
};

void copiarTexto(char dest[], int maxLen, const string& src) {
    strncpy(dest, src.c_str(), maxLen - 1);
    dest[maxLen - 1] = '';
}

Libro crearLibro(const string& t, const string& a, const string& i, float p, int st, int v) {
    Libro l;
    copiarTexto(l.titulo, sizeof(l.titulo), t);
    copiarTexto(l.autor, sizeof(l.autor), a);
    copiarTexto(l.isbn, sizeof(l.isbn), i);
    l.precio = p; l.stock = st; l.ventas = v;
    return l;
}

void agregarLibro(const string& ruta, const Libro& l) {
    ofstream arch(ruta, ios::binary | ios::out | ios::app);
    if (!arch) {
        cout << "Error al abrir " << ruta << endl;
        return;
    }
    arch.write((const char*)&l, sizeof(Libro));
    arch.close();
}

Acceso Aleatorio y Modificación In-Place (Guía Ej 6.a & 6.b)

Guía de Archivos — Ejercicio 6: Utilizando el archivo "inventario.dat" generado en el punto anterior, implementar funciones para:

a) Recuperar directamente del archivo el 3er libro y mostrar por pantalla su título y autor.
b) Reemplazar en el archivo el 2do libro con uno nuevo, cuyos datos ingresará el usuario, sin modificar el resto de los registros.

seekg para Lectura

offset = (3 - 1) * sizeof(Libro). Salto directo en O(1) al byte 256.

seekp para Escritura

Apertura ios::in | ios::out | ios::binary para sobreescribir el 2do bloque in-place.

2

Solución: Acceso Aleatorio en C++


// 6.a: Leer el 3er libro directamente (pos1 = 3)
bool leerLibroEnPos(const string& ruta, int pos1, Libro& out) {
    ifstream f(ruta, ios::binary | ios::in);
    if (!f) return false;

    int offset = (pos1 - 1) * sizeof(Libro);
    f.seekg(offset, ios::beg);

    bool ok = f.read((char*)&out, sizeof(Libro));
    f.close();
    return ok;
}

// 6.b: Reemplazar el 2do libro in-place (pos1 = 2)
bool modificarLibroEnPos(const string& ruta, int pos1, const Libro& in) {
    fstream f(ruta, ios::binary | ios::in | ios::out);
    if (!f) return false;

    int offset = (pos1 - 1) * sizeof(Libro);
    f.seekp(offset, ios::beg);

    f.write((const char*)&in, sizeof(Libro));
    bool ok = f.good();
    f.close();
    return ok;
}

Listado Completo y Auditoría de Stock (Guía Ej 6.c)

Guía de Archivos — Ejercicio 6.c: Escribir una función que muestre por pantalla el inventario completo registrado en "inventario.dat" en forma tabular.

Métricas de Auditoría requeridas:

1. Recaudación total acumulada por ventas (sumatoria de precio * cantidadVendida).
2. Alerta de libros con stock agotado (stock == 0).
3. Total de ejemplares en existencia en la librería.

Salida Tabular y Control de EOF

Usar while (arch.read((char*)&l, sizeof(Libro))) para cortar el bucle inmediatamente cuando no se pueda leer un registro completo, evitando procesar datos duplicados al final.

3

Solución: Listado y Auditoría en C++


void listarInventario(const string& ruta) {
    ifstream f(ruta, ios::binary | ios::in);
    if (!f) {
        cout << "No se pudo abrir el archivo " << ruta << endl;
        return;
    }
    Libro l;
    int nro = 1;
    float recaudacionTotal = 0;
    int stockTotal = 0;

    cout << "=== INVENTARIO COMPLETO ===" << endl;
    f.read((char*)&l, sizeof(Libro));
    while (!f.eof()) {
        float recLibro = l.precio * l.ventas;
        recaudacionTotal += recLibro;
        stockTotal += l.stock;
        cout << "#" << nro++ << " " << l.titulo 
             << " (" << l.autor << ") | Stock: " 
             << l.stock << " | Ventas: " << l.ventas 
             << " | Recaudado: ARS " << recLibro << endl;
        f.read((char*)&l, sizeof(Libro));
    }
    f.close();
    cout << "Total recaudado: ARS " << recaudacionTotal << endl;
}

Checklist de Examen: Puntos Clave

Flag ios::binary Obligatorio

En Windows, omitir ios::binary traduce automáticamente los bytes 0x0A (LF) a 0x0D 0x0A (CRLF), corrompiendo enteros y floats.

Limpieza de Flags con clear()

Si llegas a EOF durante una lectura y luego quieres hacer seekg o seekp, debes invocar obligatoriamente archivo.clear() antes de reposicionar.

Apertura ios::in | ios::out

Para modificar registros in-place, el archivo ya debe existir previamente en disco; si no existe, la apertura falla sin crearlo.

Estructuras POD (Sin Heap)

Nunca usar string ni punteros dentro del struct. Solo tipos nativos (int, float, char[]) de longitud fija.
