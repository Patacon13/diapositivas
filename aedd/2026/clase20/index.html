¿Qué es un Puntero?

Variable Convencional

Almacena directamente un valor específico del tipo de dato declarado (un entero, un caracter, un float).

Variable Puntero

Almacena una dirección de memoria RAM donde reside otro dato u objeto en el sistema.

Operadores Clave

&variable: Obtiene la dirección de memoria de la variable.
*puntero: Accede al contenido de la celda de memoria apuntada. 


#include <iostream>
using namespace std;

int main() {
    int count = 7;
    int* countPtr = nullptr; // Puntero a entero

    countPtr = &count;       // Guarda direccion de count

    cout << "Valor de count:      " << count << endl;
    cout << "Direccion (&count):   " << &count << endl;
    cout << "Puntero (countPtr):  " << countPtr << endl;
    cout << "Valor apuntado (*p): " << *countPtr << endl;

    *countPtr = 25; // Modifica count indirectamente!
    cout << "Nuevo count:         " << count << endl;

    return 0;
}

Memoria Stack vs Heap: new y delete

Memoria Stack (Pila Estática)

  • Gestionada automáticamente por el compilador.
  • Aloja variables locales y parámetros de funciones.
  • Tamaño prefijado en tiempo de compilación.
  • Se destruye automáticamente al salir del ámbito (scope).

Memoria Heap (Montículo Dinámico)

  • Espacio de memoria libre solicitado en tiempo de ejecución.
  • Se reserva con el operador new y devuelve la dirección.
  • Persiste hasta que el programador ejecute delete.
  • Permite crear listas que crecen o se achican bajo demanda.

Regla de Oro: A cada new le corresponde un delete

Si perdemos el puntero a un bloque del Heap sin haber hecho delete, esa memoria queda inaccesible hasta que finalice el proceso (Memory Leak o fuga de memoria).

Anatomía del Nodo Enlazado


// Definicion de estructura autoreferenciada
struct Nodo {
    int dato;        // Campo de informacion
    Nodo* sig;       // Puntero al siguiente Nodo
};

// Crear una lista vacia:
Nodo* cabeza = nullptr; 

// Crear el primer nodo en Heap:
cabeza = new Nodo;
cabeza->dato = 42;
cabeza->sig = nullptr;

Estructura Autoreferenciada

El campo sig es un puntero hacia otra variable del mismo tipo Nodo.

0x10A0
42
nullptr (0x0)

cabeza almacena 0x10A0. El último nodo de la lista siempre apunta a nullptr.

Inserción: Al Inicio vs Al Final

Inserción al Inicio — O(1)

Costo constante: solo se reacomodan 2 punteros sin recorrer la lista.


void insertarInicio(Nodo*& cabeza, int valor) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = valor;
    nuevo->sig = cabeza; // Enlaza al viejo inicio
    cabeza = nuevo;      // Nuevo pasa a ser cabeza
}

Inserción al Final — O(N)

Costo lineal: requiere recorrer hasta el último nodo (sig == nullptr).


void insertarFinal(Nodo*& cabeza, int valor) {
    Nodo* nuevo = new Nodo{valor, nullptr};
    if (cabeza == nullptr) {
        cabeza = nuevo;
    } else {
        Nodo* act = cabeza;
        while (act->sig != nullptr) {
            act = act->sig;
        }
        act->sig = nuevo;
    }
}

Recorrido y Búsqueda en Listas


// Patron canonico de recorrido
void mostrarLista(Nodo* cabeza) {
    Nodo* act = cabeza; // Puntero auxiliar
    while (act != nullptr) {
        cout << act->dato << " -> ";
        act = act->sig;  // Avanza al siguiente
    }
    cout << "NULL" << endl;
}

// Busqueda booleana
bool estaEnLista(Nodo* cabeza, int buscado) {
    Nodo* act = cabeza;
    while (act != nullptr) {
        if (act->dato == buscado) return true;
        act = act->sig;
    }
    return false;
}

¡Cuidado con avanzar 'cabeza'!

Si escribes cabeza = cabeza->sig en un bucle, destruyes la referencia a los nodos iniciales. Siempre usa un puntero auxiliar (Nodo* act = cabeza).

Condición de Parada

El bucle termina exactamente cuando act == nullptr. Nunca intentes acceder a act->dato si act ya es nulo.

Eliminación: Técnica de Dos Punteros


void eliminarNodo(Nodo*& cabeza, int valor) {
    Nodo* act = cabeza;
    Nodo* ant = nullptr;

    while (act != nullptr && act->dato != valor) {
        ant = act;
        act = act->sig;
    }

    if (act != nullptr) { // Encontrado
        if (ant == nullptr) {
            cabeza = act->sig;     // Era el primero
        } else {
            ant->sig = act->sig;   // Puente seguro
        }
        delete act; // Libera memoria en Heap
    }
}

El Baile de ant y act

ant vigila al nodo anterior para poder reconectar su puntero sig una vez localizado el nodo a suprimir.

Secuencia Crítica

1. Desviar el puntero: ant->sig = act->sig;
2. Liberar memoria: delete act;
¡Invertir este orden causa fallo de segmentación!

Unión de Listas Lineales Sin Repetidos (A U B)

Guía 18 — Ejercicio 1: Escribir una función en C++ que permita unir dos listas lineales A y B que contienen números enteros y devuelva A U B.

Condición: La lista resultado debe contener todos los elementos que están en A o en B, sin elementos repetidos.

Estrategia Modular

1. Recorrer listaA: si el número no está en resultado, agregarlo al final.
2. Recorrer listaB: si el número no está en resultado, agregarlo al final.

Funciones Auxiliares

Modularizar con estaEnLista(cabeza, valor) e insertarFinal(cabeza, valor) para mantener el código claro y testeable.

1

Solución: Unión Modular en C++


struct Nodo {
    int dato;
    Nodo* sig;
};

bool estaEnLista(Nodo* cabeza, int valor) {
    Nodo* act = cabeza;
    while (act != nullptr) {
        if (act->dato == valor) return true;
        act = act->sig;
    }
    return false;
}

void insertarFinal(Nodo*& cabeza, int valor) {
    Nodo* nuevo = new Nodo{valor, nullptr};
    if (cabeza == nullptr) {
        cabeza = nuevo;
    } else {
        Nodo* act = cabeza;
        while (act->sig != nullptr) act = act->sig;
        act->sig = nuevo;
    }
}
                                

Nodo* unirListas(Nodo* listaA, Nodo* listaB) {
    Nodo* res = nullptr;

    // 1. Agregar elementos de A sin repetidos
    Nodo* actA = listaA;
    while (actA != nullptr) {
        if (!estaEnLista(res, actA->dato)) {
            insertarFinal(res, actA->dato);
        }
        actA = actA->sig;
    }

    // 2. Agregar elementos de B que no esten
    Nodo* actB = listaB;
    while (actB != nullptr) {
        if (!estaEnLista(res, actB->dato)) {
            insertarFinal(res, actB->dato);
        }
        actB = actB->sig;
    }

    return res;
}

Saneamiento de Tramos No Crecientes

Guía 18 — Ejercicio 2: En una lista enlazada se guardan números naturales de hasta 4 cifras. Se cargó de manera que esté ordenada en forma creciente, pero contiene errores (tramos no crecientes).

Objetivo: Construir una función que actualice la lista original, eliminando los tramos que no están en forma creciente con delete.

Ejemplo de la Cátedra:
4 - 5 - 6 - 3 - 2 - 1 - 7 - 9 - 78 - 45 - 45 - 34 - 96 - 98 - 57
Lista Resultante Esperada:
4 - 5 - 6 - 7 - 9 - 78 - 96 - 98

Lógica de Punteros ant y act

El puntero ant permanece en el último nodo válido confirmado (ej. 6). Cuando act detecta números menores o iguales (3, 2, 1), se eliminan uno a uno liberando memoria hasta encontrar el siguiente estrictamente mayor (7).

2

Solución: Poda de Tramos en C++


struct Nodo {
    int dato;
    Nodo* sig;
};

void depurarLista(Nodo*& cabeza) {
    if (cabeza == nullptr) return;

    Nodo* ant = cabeza;
    Nodo* act = cabeza->sig;

    while (act != nullptr) {
        if (act->dato > ant->dato) {
            // Tramo creciente: ant avanza
            ant = act;
            act = act->sig;
        } else {
            // Tramo no creciente: se poda
            Nodo* aBorrar = act;
            act = act->sig;      // Avanza explorador
            ant->sig = act;      // Puentea el nodo
            delete aBorrar;      // Libera memoria
        }
    }
}

Invariante del Algoritmo

ant->dato siempre contiene el máximo valor creciente alcanzado hasta el momento. Cualquier nodo posterior que no lo supere es eliminado.

Gestión Estricta de Heap

Nótese cómo aBorrar guarda el puntero temporal antes de hacer act = act->sig. Si hiciéramos delete act primero, leer act->sig sería un acceso ilegal a memoria.

Integración de Calificaciones y Ranking por Promedio

Guía 18 — Ejercicio 4: En dos listas Curso1 y Curso2 de tipo CALIFICACIONES se tienen las notas de alumnos de dos comisiones de ISI en las 6 materias de 1er año (ordenadas por ID Alumno).

Información del nodo inicial: ID Alumno (6 cifras) y un vector con las 6 notas finales.

Requerimiento: Integrar ambas listas generando una nueva lista INTEGRADA ordenada por promedio de mayor a menor (descendente) conteniendo en cada nodo solamente el ID y el promedio obtenido (float).

Cálculo de Promedio

Suma de las 6 notas dividido 6.0 (división real en punto flotante).

Inserción Ordenada Descendente

Buscar posición donde nuevo->promedio > act->promedio para insertar al inicio o entre dos nodos.

3

Solución: Integración y Ranking en C++


struct NodoCalificaciones {
    int idAlumno;
    int notas[6];
    NodoCalificaciones* sig;
};

struct NodoIntegrada {
    int idAlumno;
    float promedio;
    NodoIntegrada* sig;
};

float calcularPromedio(const int notas[6]) {
    float suma = 0;
    for (int i = 0; i < 6; i++) suma += notas[i];
    return suma / 6.0f;
}
                                

void insertarDescendente(NodoIntegrada*& cabeza, 
                         int id, float prom) {
    NodoIntegrada* nuevo = new NodoIntegrada{id, prom, nullptr};
    NodoIntegrada* act = cabeza;
    NodoIntegrada* ant = nullptr;

    while (act != nullptr && act->promedio >= prom) {
        ant = act;
        act = act->sig;
    }
    nuevo->sig = act;
    if (ant == nullptr) cabeza = nuevo;
    else ant->sig = nuevo;
}

NodoIntegrada* integrar(NodoCalificaciones* c1, 
                        NodoCalificaciones* c2) {
    NodoIntegrada* res = nullptr;
    for (NodoCalificaciones* p = c1; p; p = p->sig)
        insertarDescendente(res, p->idAlumno, calcularPromedio(p->notas));
    for (NodoCalificaciones* p = c2; p; p = p->sig)
        insertarDescendente(res, p->idAlumno, calcularPromedio(p->notas));
    return res;
}

Checklist de Examen: Trampas Frecuentes

Puntero Nulo (Null Dereference)

Intentar hacer p->sig o p->dato cuando p == nullptr provoca aborto inmediato del programa (Segmentation fault).

Paso por Referencia

Si una función puede modificar el primer elemento de la lista, debes pasar el puntero por referencia: Nodo*& cabeza.

Punteros Colgantes (Dangling)

Nunca uses un puntero después de haber ejecutado delete sobre la dirección a la que apunta. Asignarle nullptr si continúa en ámbito.

Liberación Total al Cierre

Todo programa profesional debe recorrer la lista y liberar cada nodo con delete antes de finalizar el proceso.
