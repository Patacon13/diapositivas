Contexto: Ciudades de Santa Fe

Parcial 4

La provincia de Santa Fe tiene información sobre las ciudades de la provincia en listas enlazadas simples (en cada lista vienen varias ciudades del mismo departamento).

En cada nodo de una lista enlazada con ciudades, la información almacenada es:

  • Código Departamento: entero en 1..20
  • Nombre de la ciudad: 30 caracteres
  • Cantidad de habitantes: entero sin signo
  • Sector: 0: Sur, 1: Centro, 2: Norte

Lectura atenta: Antes de tirar código, identificá los tipos exactos de cada campo, la longitud real del arreglo de caracteres y qué debe ser un struct separado para facilitar la copia de nodos.

a

Declaración de Estructuras

Inciso a

Declarar las estructuras de datos necesarias para manejar una lista Ciudades con estas características, y una variable Start, que pueda utilizarse para apuntar al comienzo de la misma.

Puntos clave a verificar

¿Cuántos bytes necesita una cadena C de 30 caracteres? ¿Qué tipo representa un entero sin signo? ¿En qué valor debe quedar inicializada Start?

Solución: Estructuras de Datos


struct Ciudad {
    int codDepto;               // 1..20
    char nombre[31];            // 30 caracteres + '\0'
    unsigned int habitantes;    // entero sin signo
    int sector;                 // 0: Sur, 1: Centro, 2: Norte
};

struct Nodo {
    Ciudad info;
    Nodo* sig;
};

typedef Nodo* ListaCiudades;

// Variable solicitada para apuntar al comienzo
ListaCiudades Start = NULL;

// Estructura auxiliar para retornar totales en el inciso c)
struct HabitantesPorSector {
    unsigned long sur;
    unsigned long centro;
    unsigned long norte;
};

Separar Ciudad de Nodo permite copiar todos los datos de una ciudad con una sola asignación (nuevo->info = aux->info;) en los incisos siguientes.

b

Diseño sin Codificar

Inciso b

Se dispone de varias listas de Ciudades (una por Departamento) ya cargadas y ordenadas por cantidad de habitantes de menor a mayor.

Diseñar ItemB() que recibe dos listas de Ciudades, un entero X y un entero Cant: retornar una lista con las X ciudades de las dos listas que tengan más de Cant habitantes, ordenada de mayor a menor (ambas listas no están vacías).

Explique brevemente con sus palabras —sin codificar— dos formas diferentes de cumplir con este requerimiento.

b

Dos Estrategias Diferentes (Sin Código)

Forma 1: Merge + Inserción en Cabecera

  1. Avanzar en ambas listas salteando los nodos con habitantes <= Cant (aprovechando que vienen de menor a mayor).
  2. Hacer un merge (intercalación) tomando siempre el menor de los dos frentes.
  3. Insertar cada copia al principio de la lista resultado: al entrar de menor a mayor por la cabeza, queda ordenada de mayor a menor. Si supera X nodos, se elimina el último.

Forma 2: Merge + Pila Auxiliar (LIFO)

  1. Descartar en ambas listas el prefijo con habitantes <= Cant.
  2. Intercalar ambas listas tomando el menor frente y apilar cada elemento en una Pila auxiliar (los más poblados quedan en el tope).
  3. Desapilar hasta X ciudades (o hasta vaciar la pila) e ir agregándolas al final de la lista resultado, quedando de mayor a menor.

Alternativa válida: Recorrer ambas listas e ir aplicando inserción ordenada descendente en la lista resultado (podando el último nodo si se excede X), técnica clave para el inciso c) donde una lista viene desordenada.

c

Codificación con Restricciones

Inciso c

Codificar la función ItemC() retornando la misma lista resultado que en ItemB(), respetando:

  • Lista A ordenada de menor a mayor; lista B sin ningún orden.
  • Ninguna lista recibida puede modificarse.
  • No está permitido usar algoritmos de ordenamiento sobre listas.
  • La lista resultado debe pasarse como parámetro.
  • La función debe retornar la cantidad de habitantes por cada sector de la provincia.

Cuidado con B desordenada: Si cortás el ciclo apenas insertás X ciudades, una ciudad enorme al final de B quedaría afuera. Solución: insertar ordenado descendente y, si se supera X, podar el último nodo.

c

Solución (1/2): Auxiliares de Lista


Nodo* crearNodo(const Ciudad& c) {
    Nodo* nuevo = new Nodo;
    nuevo->info = c;
    nuevo->sig = NULL;
    return nuevo;
}

void insertarOrdenadoDesc(ListaCiudades& lista, const Ciudad& c) {
    Nodo* nuevo = crearNodo(c);
    if (lista == NULL || c.habitantes >= lista->info.habitantes) {
        nuevo->sig = lista;
        lista = nuevo;
    } else {
        Nodo* actual = lista;
        while (actual->sig != NULL &&
               actual->sig->info.habitantes > c.habitantes) {
            actual = actual->sig;
        }
        nuevo->sig = actual->sig;
        actual->sig = nuevo;
    }
}

void eliminarUltimo(ListaCiudades& lista) {
    if (lista != NULL) {
        if (lista->sig == NULL) {
            delete lista;
            lista = NULL;
        } else {
            Nodo* actual = lista;
            while (actual->sig->sig != NULL) {
                actual = actual->sig;
            }
            delete actual->sig;
            actual->sig = NULL;
        }
    }
}
c

Solución (2/2): ItemC() Modularizada


void acumularSector(HabitantesPorSector& tot, const Ciudad& c) {
    switch (c.sector) {
        case 0: tot.sur += c.habitantes; break;
        case 1: tot.centro += c.habitantes; break;
        case 2: tot.norte += c.habitantes; break;
    }
}

void procesarListaOrdenada(ListaCiudades A, int X, unsigned int Cant,
                           ListaCiudades& res, int& cantIns,
                           HabitantesPorSector& tot) {
    Nodo* aux = A;
    while (aux != NULL && aux->info.habitantes <= Cant) {
        acumularSector(tot, aux->info);
        aux = aux->sig;
    }
    while (aux != NULL) {
        acumularSector(tot, aux->info);
        if (X > 0) {
            insertarOrdenadoDesc(res, aux->info);
            cantIns++;
            if (cantIns > X) {
                eliminarUltimo(res);
                cantIns--;
            }
        }
        aux = aux->sig;
    }
}

void procesarListaDesordenada(ListaCiudades B, int X, unsigned int Cant,
                              ListaCiudades& res, int& cantIns,
                              HabitantesPorSector& tot) {
    Nodo* aux = B;
    while (aux != NULL) {
        acumularSector(tot, aux->info);
        if (X > 0 && aux->info.habitantes > Cant) {
            insertarOrdenadoDesc(res, aux->info);
            cantIns++;
            if (cantIns > X) {
                eliminarUltimo(res);
                cantIns--;
            }
        }
        aux = aux->sig;
    }
}

HabitantesPorSector ItemC(ListaCiudades A, ListaCiudades B, int X,
                          unsigned int Cant, ListaCiudades& resultado) {
    resultado = NULL;
    HabitantesPorSector totales = {0, 0, 0};
    int cantInsertados = 0;
    procesarListaOrdenada(A, X, Cant, resultado, cantInsertados, totales);
    procesarListaDesordenada(B, X, Cant, resultado, cantInsertados, totales);
    return totales;
}

Checklist: Trampas Clásicas de Parcial 4

1. Pisar el puntero original

Nunca hagas A = A->sig; directamente si necesitás preservar la referencia o si se pasa por referencia. Usá siempre Nodo* aux = A;.

2. Compartir nodos sin new

Enlazar un nodo existente de A o B dentro de resultado modifica su campo ->sig y rompe la lista original.

3. Basura en resultado

Siempre inicializá resultado = NULL; al comienzo de ItemC(). Si venía sin inicializar, insertarOrdenadoDesc falla.

4. Fuga al podar a X

Si desenganchás el último nodo para no superar X, recordá hacer delete para no dejar memoria huérfana en el Heap.
