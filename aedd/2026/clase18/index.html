¿Por Qué Archivos? RAM vs Persistencia

Memoria RAM (Volátil)

• Acceso ultra-rápido a celdas de memoria contiguas.

• Variables, arreglos y TDAs residen en RAM.

• Al finalizar el programa o reiniciarse el equipo, su contenido desaparece por completo.

Archivo en Disco (Persistente)

• Soporte de almacenamiento secundario (SSD / HDD).

• Capacidad masiva e independiente de la ejecución.

• La informacion sobrevive entre ejecuciones y puede compartirse entre aplicaciones.

Definición: Un Archivo de Texto es una secuencia secuencial de caracteres codificados (generalmente ASCII o UTF-8) organizados en renglones separados por saltos de linea (\n).

Biblioteca <fstream>: Clases Principales

Para manipular archivos debemos incluir #include <fstream> en nuestro programa:

ifstream

Input File Stream

Exclusivo para lectura de datos desde archivo hacia el programa. Modo implicito: ios::in.

ofstream

Output File Stream

Exclusivo para escritura. Crea el archivo si no existe y por defecto trunca su contenido previo (ios::out).

fstream

File Stream

Flujo bidireccional que permite combinar operaciones de lectura y escritura sobre el mismo archivo.

Modos Frecuentes de Apertura

ios::in (lectura) • ios::out (escritura con truncado) • ios::app (append: conserva lo existente y anexa al final).

Apertura y Control de Errores

NUNCA asumir que el archivo abrio exitosamente. Puede no existir, tener la ruta mal escrita o no contar con permisos en el sistema operativo.

Formas de Verificacion

• if (!archivo) → Operador de conversion booleana.

• if (archivo.fail()) → Retorna true si hubo falla.

• if (!archivo.is_open()) → Verifica conexion activa.


#include <iostream>
#include <fstream>

using namespace std;

int main() {
    ifstream entrada("datos.txt");

    if (!entrada.is_open()) {
        cout << "Error: no se pudo abrir el archivo." << endl;
    } else {
        cout << "Archivo abierto correctamente." << endl;
        // Operaciones seguras de lectura...
        entrada.close();
    }
    return 0;
}

Lectura Formateada (Operador >>)

Ideal para leer datos con tipos conocidos separados por espacios en blanco, tabulaciones o saltos de linea:

Salteo Automatico de Espacios

Ignora espacios, tabulaciones y enters previos al dato.

Conversion de Tipos

Parsea el texto directamente a int, float o string (hasta el proximo espacio).


// Archivo calificaciones.txt:
// Perez 85 90
// Gomez 70 82

ifstream arch("calificaciones.txt");
if (arch.is_open()) {
    string apellido;
    int nota1, nota2;
    
    // El propio flujo en la condicion controla el exito
    while (arch >> apellido >> nota1 >> nota2) {
        cout << apellido << ": " 
             << (nota1 + nota2) / 2.0 << endl;
    }
    arch.close();
}

Lectura Línea a Línea (getline)

Permite leer renglones completos conservando espacios intermedios:

Sintaxis Estandar

getline(archivo, variableString);
Lee hasta encontrar el caracter de salto de linea (\n).

Delimitador Personalizado

getline(archivo, campo, ',');
Fundamental para procesar archivos CSV o columnas separadas por comas/puntos y coma.


// Archivo bitacora.txt con parrafos enteros

ifstream bitacora("bitacora.txt");
if (bitacora.is_open()) {
    string renglon;
    int numeroLinea = 1;

    while (getline(bitacora, renglon)) {
        cout << "[" << numeroLinea << "] " 
             << renglon << endl;
        numeroLinea++;
    }
    bitacora.close();
}

Lectura por Carácter (Método get)

Cuando necesitamos procesar absolutamente cada byte sin perder nada:

Cero Perdida de Formato

A diferencia de >>, el metodo get() NO saltea espacios, tabulaciones ni saltos de linea.

Casos Tipicos de Aplicacion

Algoritmos de cifrado, compresion, conteo estricto de caracteres y parsing sintactico.


ifstream fuente("codigo.txt");
if (fuente.is_open()) {
    char c;
    int totalBytes = 0;

    // Lee cada caracter individual
    while (fuente.get(c)) {
        totalBytes++;
        // Analisis caracter por caracter...
    }
    cout << "Total de caracteres: " 
         << totalBytes << endl;
    fuente.close();
}

Escritura y Cierre de Archivos

Escritura con Operador <<

Permite insertar cualquier tipo de dato exactamente igual que con cout. Usar \n o endl para saltos de renglon.

¿Por que es vital archivo.close()?

• Flush del Buffer: Garantiza que los datos en RAM se graben efectivamente en el disco fisico.

• Liberacion del Descriptor: Evita fugas de recursos en el sistema operativo.


#include <iostream>
#include <fstream>

using namespace std;

int main() {
    // Abre para escritura (crea o sobreescribe)
    ofstream reporte("resumen.txt");

    if (reporte.is_open()) {
        reporte << "=== REPORTE ACADEMICO ===" << endl;
        reporte << "Materia: Algoritmos" << endl;
        reporte << "Alumnos evaluados: " << 145 << endl;
        
        reporte.close(); // Vaciado y cierre seguro
        cout << "Archivo generado con exito." << endl;
    }
    return 0;
}

Conteo de Letras, Digitos y Caracteres

Enunciado: Leer un archivo de texto llamado texto.txt y contar cuantitativamente:

a) La cantidad de letras del alfabeto (mayusculas y minusculas).

b) La cantidad de digitos numericos ('0' a '9').

c) La cantidad de otros caracteres (espacios, saltos de linea y puntuacion).

Mostrar por pantalla un resumen completo al finalizar la ejecucion.

Clave de Diseño

Debemos utilizar archivo.get(c) porque si usaramos archivo >> c los espacios y saltos de linea serian descartados automaticamente.

1

Solución Modular en C++


// Funciones auxiliares modulares
bool esLetra(char c) {
    bool res = false;
    if ((c >= 'a' && c <= 'z') || 
        (c >= 'A' && c <= 'Z')) {
        res = true;
    }
    return res;
}

bool esDigito(char c) {
    bool res = false;
    if (c >= '0' && c <= '9') {
        res = true;
    }
    return res;
}
                                

// Flujo caracter a caracter
void analizarArchivo(const string& ruta, 
                     int& l, int& d, int& o) {
    ifstream arch(ruta);
    l = 0; d = 0; o = 0;
    if (arch.is_open()) {
        char c;
        while (arch.get(c)) {
            if (esLetra(c)) { l++; }
            else if (esDigito(c)) { d++; }
            else { o++; }
        }
        arch.close();
    }
}

Cifrado César de un Archivo

Enunciado: Leer un archivo de texto (original.txt) y generar un archivo cifrado en clave (enclave.txt).

Escribir en clave consiste en sumar un desplazamiento entero (shift) ingresado por teclado al codigo ASCII de cada caracter.

Restriccion: Los espacios en blanco y los saltos de linea no se alteran para mantener la legibilidad de la estructura del documento.

Enfoque Tecnico

Abrimos simultaneamente un ifstream para el origen y un ofstream para el destino, procesando flujo caracter a caracter con get() y put().

2

Solución Modular: Cifrado en Disco


// Transformacion con rotacion ciclica
char cifrarCaracter(char c, int shift) {
    char res = c;
    if (c >= 'A' && c <= 'Z') {
        int nuevoCodigo = c + shift;
        if (nuevoCodigo > 'Z') {
            nuevoCodigo = nuevoCodigo - 26;
        }
        res = (char) nuevoCodigo;
    } else if (c >= 'a' && c <= 'z') {
        int nuevoCodigo = c + shift;
        if (nuevoCodigo > 'z') {
            nuevoCodigo = nuevoCodigo - 26;
        }
        res = (char) nuevoCodigo;
    }
    return res;
}

Rotacion ciclica: Si supera 'Z' (o 'z'), vuelve a 'A' (o 'a'). Se preservan espacios, saltos y signos. 


// Proceso simultaneo entrada → salida
bool cifrarArchivo(const string& orig, 
                   const string& dest, 
                   int shift) {
    ifstream entrada(orig);
    ofstream salida(dest);
    bool exito = false;

    if (entrada.is_open() && salida.is_open()) {
        char c;
        while (entrada.get(c)) {
            char cif = cifrarCaracter(c, shift);
            salida.put(cif);
        }
        entrada.close();
        salida.close();
        exito = true;
    }
    return exito;
}

Estadísticas de Palabras en Texto

Enunciado: Leer un archivo de texto e informar:

1. La cantidad total de palabras del texto.

2. La longitud de la palabra mas larga y cual fue.

3. La cantidad de palabras que comienzan y terminan con letras elegidas por el usuario (sin distinguir mayusculas/minusculas).

Estrategia Optima

Usamos archivo >> palabra. El operador extrae exactamente una palabra en cada iteracion ignorando espacios y saltos de linea.

3

Solución Modular: Análisis de Palabras


char aMinuscula(char c) {
    char res = c;
    if (c >= 'A' && c <= 'Z') { 
        res = static_cast<char>(c + ('a' - 'A')); 
    }
    return res;
}

bool coincideExtremos(const string& pal, 
                      char inicio, char fin) {
    bool coincide = false;
    if (pal.length() > 0) {
        char p = aMinuscula(pal[0]);
        char u = aMinuscula(pal[pal.length()-1]);
        if (p == aMinuscula(inicio) && 
            u == aMinuscula(fin)) {
            coincide = true;
        }
    }
    return coincide;
}
                                

// Bucle formateado palabra por palabra
while (arch >> palabra) {
    totalPalabras++;
    if (palabra.length() > maxLongitud) {
        maxLongitud = palabra.length();
        palabraMasLarga = palabra;
    }
    if (coincideExtremos(palabra, ini, fin)) { 
        cantFiltro++; 
    }
}

Ventaja: No necesitamos bucles manuales buscando espacios; el stream tokeniza de forma natural.

Registros Estructurados en Archivos CSV

Caso Real: Un archivo de texto alumnos.csv almacena datos separados por comas:

Legajo,Nombre,Nota1,Nota2
10452,Lucia Martinez,8.5,9.0

Se solicita leer el archivo, calcular el promedio de cada alumno y determinar el mejor promedio del curso.

Herramienta Clave

Aplicamos getline(archivo, campo, ',') pasando la coma como caracter delimitador para aislar cada columna de texto.

4

Solución Modular: Parsing CSV


struct Alumno {
    int legajo;
    string nombre;
    float promedio;
};

float calcularProm(float n1, float n2) {
    float res = (n1 + n2) / 2.0f;
    return res;
}

stoi convierte texto a entero y stof a flotante. 


// Lectura de registro delimitado
string sLeg, nom, sN1, sN2;
while (getline(arch, sLeg, ',') &&
       getline(arch, nom, ',') &&
       getline(arch, sN1, ',') &&
       getline(arch, sN2)) {
    
    Alumno a;
    a.legajo = stoi(sLeg);
    a.nombre = nom;
    a.promedio = calcularProm(stof(sN1), 
                              stof(sN2));
    
    cout << a.legajo << " | " << a.nombre 
         << " | Prom: " << a.promedio << endl;
}

Checklist de Examen: Archivos de Texto

1. Verificacion Obligatoria

Siempre comprobar if (!archivo.is_open()) antes de intentar leer o escribir.

2. Control de Fin de Archivo

Usar while (arch >> x) o while (getline(arch, s)). Nunca while(!arch.eof()) previo.

3. Cierre Incondicional

Cerrar con archivo.close() para forzar el vaciado del buffer y liberar el descriptor del sistema.

4. Limpieza al Mezclar cin y getline

Si leemos con cin >> x y luego usamos getline, limpiar el enter residual con cin >> ws;.
