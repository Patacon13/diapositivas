¿Qué es un TDA?

Definición

Un Tipo de Dato Abstracto (TDA) es un modelo matemático compuesto por un conjunto de valores y un conjunto de operaciones primitivas definidas sobre esos valores.

Entradas

CAJA NEGRA

Ocultamiento de Información
(Representación interna privada)

Salidas

Interfaz Pública

Define qué operaciones se pueden realizar (visibles para el usuario/cliente).

Implementación Privada

Define cómo se almacenan los datos y cómo funcionan los algoritmos internos.

Estructura Modular en C++

archivo.h

Interfaz / Declaración

  • Definición del struct o tipo de dato.
  • Prototipos de funciones primitivas.
  • Documentación de uso (pre/post-condiciones).

archivo.cpp

Implementación

  • Código fuente de cada operación primitiva.
  • Incluye #include "archivo.h".
  • Oculta los detalles al programa cliente.

main.cpp

Programa Cliente

  • Utiliza el TDA a través de su interfaz pública.
  • No accede a campos internos si se desea encapsular.
  • Crea y manipula instancias del tipo.

TDA Contador

Guía Práctica

Implementar el TDA Contador. Su interfaz debe permitir crear variables del tipo e implementar las operaciones para incrementar (++) y decrementar (--) su valor.

Interfaz pública propuesta:

  • Contador crear(int valor);
  • void incrementar(Contador &c, int pasos);
  • void decrementar(Contador &c, int pasos);
  • int toInteger(Contador c);

Presioná Flecha Abajo para ver la solución y análisis

1

Solución: TDA Contador


struct Contador {
    int valor;
};

Contador crear(int valor) {
    Contador c;
    c.valor = valor;
    return c;
}

void incrementar(Contador &c, int pasos) {
    c.valor += pasos;
}

void decrementar(Contador &c, int pasos) {
    c.valor -= pasos;
}

int toInteger(Contador c) {
    return c.valor;
}

Cuadrado

Rectángulo

  • Rectangulo crear_rectangulo(float b, float h);
  • float perimetro(Rectangulo r);
  • float area(Rectangulo r);

Triángulo

  • float perimetro(Triangulo t);
  • float area(Triangulo t);

Solución: TDAs Figuras


const float PI = 3.14159265f;

struct Circulo {
    float radio;
};
Circulo crear_circulo(float r) {
    Circulo c;
    c.radio = r;
    return c;
}
float perimetro(Circulo c) {
    return 2.0f * PI * c.radio;
}
float area(Circulo c) {
    return PI * c.radio * c.radio;
}

struct Cuadrado {
    float lado;
};
Cuadrado crear_cuadrado(float l) {
    Cuadrado c;
    c.lado = l;
    return c;
}
float perimetro(Cuadrado c) {
    return 4.0f * c.lado;
}
float area(Cuadrado c) {
    return c.lado * c.lado;
}

struct Rectangulo {
    float base;
    float altura;
};
Rectangulo crear_rectangulo(float b, float h) {
    Rectangulo r;
    r.base = b;
    r.altura = h;
    return r;
}
float perimetro(Rectangulo r) {
    return 2.0f * (r.base + r.altura);
}
float area(Rectangulo r) {
    return r.base * r.altura;
}

struct Triangulo {
    float base;
    float altura;
    float l1, l2, l3;
};
Triangulo crear_triangulo(float b, float h, float l1, float l2, float l3) {
    Triangulo t;
    t.base = b;
    t.altura = h;
    t.l1 = l1; t.l2 = l2; t.l3 = l3;
    return t;
}
float perimetro(Triangulo t) {
    return t.l1 + t.l2 + t.l3;
}
float area(Triangulo t) {
    return (t.base * t.altura) / 2.0f;
}

Menú Cliente de Figuras

Guía Práctica

Implementar un programa cliente que muestre un menú con las distintas formas geométricas y que al acceder a la elegida se presente un submenú con la posibilidad de:

  1. Crear la figura.
  2. Mostrar el perímetro.
  3. Mostrar el área.

Nota importante: Para poder mostrar perímetro y área, la figura debe haber sido creada previamente.

Solución: Programa Cliente


void gestionarCirculo() {
    Circulo c;
    bool creada = false;
    int opcion = -1;

    while (opcion != 0) {
        cout << "1. Crear | 2. Perimetro | 3. Area | 0. Volver: ";
        cin >> opcion;

        switch (opcion) {
            case 1: {
                float r;
                cout << "Radio: ";
                cin >> r;
                c = crear_circulo(r);
                creada = true;
                break;
            }
            case 2:
                if (creada) cout << "Perimetro: " << perimetro(c) << endl;
                else cout << "Error: Cree el circulo primero." << endl;
                break;
            case 3:
                if (creada) cout << "Area: " << area(c) << endl;
                else cout << "Error: Cree el circulo primero." << endl;
                break;
            case 0:
                break;
            default:
                cout << "Opcion invalida." << endl;
                break;
        }
    }
}

TDA Hora y Operaciones

Guía Práctica

Definir la representación necesaria para manipular un TDA Hora. Almacena hora, minutos y segundos en notación 24 horas.

  • Hora ponerAHora(int hora, int min, int seg): configura el reloj validando rangos.
  • void mostrar24(Hora h): imprime en formato hh:mm:ss.
  • void mostrar12(Hora h): imprime en formato hh:mm:ss a.m./p.m..
  • void adelantar(Hora &h, int minutos): adelanta la hora X minutos.
  • void atrasar(Hora &h, int minutos): atrasa la hora X minutos.
  • int diferenciaEnMinutos(Hora h1, Hora h2): diferencia absoluta en minutos.
  • int diferenciaEnSegundos(Hora h1, Hora h2): diferencia absoluta en segundos.

Presioná Flecha Abajo para ver la solución y análisis

4a

Solución: TDA Hora


struct Hora {
    int hora, min, seg;
};

Hora ponerAHora(int h, int m, int s) {
    Hora nueva;
    if (h >= 0 && h < 24) nueva.hora = h;
    else nueva.hora = 0;

    if (m >= 0 && m < 60) nueva.min = m;
    else nueva.min = 0;

    if (s >= 0 && s < 60) nueva.seg = s;
    else nueva.seg = 0;

    return nueva;
}

void mostrar12(Hora h) {
    int h12 = h.hora;
    string sufijo = " a.m.";
    if (h.hora >= 12) {
        sufijo = " p.m.";
        if (h.hora > 12) h12 = h.hora - 12;
    } else {
        if (h.hora == 0) h12 = 12;
    }
    if (h12 < 10) cout << "0";
    cout << h12 << ":";
    if (h.min < 10) cout << "0";
    cout << h.min << ":";
    if (h.seg < 10) cout << "0";
    cout << h.seg << sufijo << endl;
}

void adelantar(Hora &h, int minutos) {
    int total = (h.hora * 60 + h.min + minutos) % (24 * 60);
    if (total < 0) total += (24 * 60);
    h.hora = total / 60;
    h.min = total % 60;
}

void atrasar(Hora &h, int minutos) {
    adelantar(h, -minutos);
}

int diferenciaEnMinutos(Hora h1, Hora h2) {
    int diff = (h1.hora * 60 + h1.min) - (h2.hora * 60 + h2.min);
    if (diff < 0) diff = -diff;
    return diff;
}

Gestor de Eventos

Guía Práctica

Escribir un programa cliente que, dada una lista de eventos (nombre y duración esperada en minutos) y la hora de inicio del primer evento, muestre por pantalla la hora de comienzo y fin de cada uno de los eventos.

La lista de eventos se almacena en un arreglo estático de hasta 10 elementos. Las horas se van encadenando progresivamente.

Presioná Flecha Abajo para ver la solución y análisis

4b

Solución: Gestor de Eventos


struct Evento {
    string nombre;
    int duracionMinutos;
};

void cronogramaEventos(Evento eventos[], int cant, Hora inicio) {
    Hora actual = inicio;

    for (int i = 0; i < cant; i++) {
        Hora fin = actual;
        adelantar(fin, eventos[i].duracionMinutos);

        cout << "Evento: " << eventos[i].nombre << endl;
        cout << "  Inicio: "; mostrar24(actual);
        cout << "  Fin:    "; mostrar24(fin);
        cout << "--------------------" << endl;

        actual = fin;
    }
}
