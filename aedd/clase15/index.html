¿Qué es un TDA?

Definición

Un Tipo de Dato Abstracto (TDA) es un modelo matemático compuesto por un conjunto de valores y un conjunto de operaciones primitivas definidas sobre esos valores.

Entradas

CAJA NEGRA

Ocultamiento de Información
(Representación interna privada)

Salidas

Interfaz Pública

Define qué operaciones se pueden realizar (visibles para el usuario/cliente).

Implementación Privada

Define cómo se almacenan los datos y cómo funcionan los algoritmos internos.

Estructura Modular en C++

archivo.h

Interfaz / Declaración

  • Definición del struct o tipo de dato.
  • Prototipos de funciones primitivas.
  • Documentación de uso (pre/post-condiciones).

archivo.cpp

Implementación

  • Código fuente de cada operación primitiva.
  • Incluye #include "archivo.h".
  • Oculta los detalles al programa cliente.

main.cpp

Programa Cliente

  • Utiliza el TDA a través de su interfaz pública.
  • No accede a campos internos si se desea encapsular.
  • Crea y manipula instancias del tipo.

Solución: TDAs Figuras


const float PI = 3.14159265f;

struct Circulo {
    float radio;
};
Circulo crear_circulo(float r) {
    Circulo c;
    c.radio = r;
    return c;
}
float perimetro(Circulo c) {
    return 2.0f * PI * c.radio;
}
float area(Circulo c) {
    return PI * c.radio * c.radio;
}

struct Cuadrado {
    float lado;
};
Cuadrado crear_cuadrado(float l) {
    Cuadrado c;
    c.lado = l;
    return c;
}
float perimetro(Cuadrado c) {
    return 4.0f * c.lado;
}
float area(Cuadrado c) {
    return c.lado * c.lado;
}

struct Rectangulo {
    float base;
    float altura;
};
Rectangulo crear_rectangulo(float b, float h) {
    Rectangulo r;
    r.base = b;
    r.altura = h;
    return r;
}
float perimetro(Rectangulo r) {
    return 2.0f * (r.base + r.altura);
}
float area(Rectangulo r) {
    return r.base * r.altura;
}

struct Triangulo {
    float base;
    float altura;
    float l1, l2, l3;
};
Triangulo crear_triangulo(float b, float h, float l1, float l2, float l3) {
    Triangulo t;
    t.base = b;
    t.altura = h;
    t.l1 = l1; t.l2 = l2; t.l3 = l3;
    return t;
}
float perimetro(Triangulo t) {
    return t.l1 + t.l2 + t.l3;
}
float area(Triangulo t) {
    return (t.base * t.altura) / 2.0f;
}

TDA Hora y Operaciones

Guía Práctica

Definir la representación necesaria para manipular un TDA Hora. Almacena hora, minutos y segundos en notación 24 horas.

  • Hora ponerAHora(int hora, int min, int seg): configura el reloj validando rangos.
  • void mostrar24(Hora h): imprime en formato hh:mm:ss.
  • void mostrar12(Hora h): imprime en formato hh:mm:ss a.m./p.m..
  • void adelantar(Hora &h, int minutos): adelanta la hora X minutos.
  • void atrasar(Hora &h, int minutos): atrasa la hora X minutos.
  • int diferenciaEnMinutos(Hora h1, Hora h2): diferencia absoluta en minutos.

Solución: TDA Hora


struct Hora {
    int hora, min, seg;
};

Hora ponerAHora(int h, int m, int s) {
    Hora nueva;
    if (h >= 0 && h < 24) nueva.hora = h;
    else nueva.hora = 0;

    if (m >= 0 && m < 60) nueva.min = m;
    else nueva.min = 0;

    if (s >= 0 && s < 60) nueva.seg = s;
    else nueva.seg = 0;

    return nueva;
}

void mostrar12(Hora h) {
    int h12 = h.hora;
    string sufijo = " a.m.";
    if (h.hora >= 12) {
        sufijo = " p.m.";
        if (h.hora > 12) h12 = h.hora - 12;
    } else {
        if (h.hora == 0) h12 = 12;
    }
    if (h12 < 10) cout << "0";
    cout << h12 << ":";
    if (h.min < 10) cout << "0";
    cout << h.min << ":";
    if (h.seg < 10) cout << "0";
    cout << h.seg << sufijo << endl;
}

void adelantar(Hora &h, int minutos) {
    int total = (h.hora * 60 + h.min + minutos) % (24 * 60);
    if (total < 0) total += (24 * 60);
    h.hora = total / 60;
    h.min = total % 60;
}

void atrasar(Hora &h, int minutos) {
    adelantar(h, -minutos);
}

int diferenciaEnMinutos(Hora h1, Hora h2) {
    int diff = (h1.hora * 60 + h1.min) - (h2.hora * 60 + h2.min);
    if (diff < 0) diff = -diff;
    return diff;
}

TDA Pila: Acceso LIFO

Estructura Lineal

Estructura LIFO (Last-In, First-Out)

Solo se tiene acceso al último elemento ingresado: TOS (Top of Stack / Cima).

Push (Apilar) Pop (Desapilar)
Dato Base [0]
Dato Intermedio [1]
Dato Cima [2]
TOS (Cima)

Analogía: Pila de platos (se coloca y retira siempre por arriba).

En la Memoria: Call Stack

El procesador organiza las llamadas a funciones y sus variables locales utilizando exactamente una pila:

0xFFFF Función activa (Cima / TOS)
0xFFE0 Variables locales de funcion()
0xFA00 Frame de llamada de main()
0x0000 Variables globales y código

Al invocar una función, se apila su marco; al retornar con return, se desapila.

TDA Pila: Especificación

Operaciones Primitivas

Implementar el TDA Pila con un arreglo estático de enteros y su índice de tope. Debe proveer las siguientes operaciones:

  • Pila crear(): inicializa y retorna una pila vacía (tope en -1).
  • bool vacia(Pila p): devuelve true si la pila no tiene elementos.
  • bool llena(Pila p): devuelve true si se alcanzó la capacidad máxima.
  • void apilar(Pila &p, int elem): añade un nuevo elemento en la cima (push).
  • void desapilar(Pila &p): elimina el elemento de la cima (pop).
  • int cima(Pila p): devuelve el valor en la cima sin retirarlo (top/peek).

Solución: TDA Pila


const int MAX_PILA = 100;

struct Pila {
    int datos[MAX_PILA];
    int tope;
};

Pila crear() {
    Pila p;
    p.tope = -1;
    return p;
}

bool vacia(Pila p) {
    return p.tope == -1;
}

bool llena(Pila p) {
    return p.tope == MAX_PILA - 1;
}

void apilar(Pila &p, int elem) {
    if (!llena(p)) {
        p.tope++;
        p.datos[p.tope] = elem;
    }
}

void desapilar(Pila &p) {
    if (!vacia(p)) {
        p.tope--;
    }
}

int cima(Pila p) {
    int elem = -1;
    if (!vacia(p)) {
        elem = p.datos[p.tope];
    }
    return elem;
}

TDA Cola: Acceso FIFO

Estructura Lineal

Estructura FIFO (First-In, First-Out)

Inserción por un extremo (Final) y extracción por el otro extremo (Frente).

Desencolar (Pop / Frente) Encolar (Push / Final)
D1 Frente
D2 En cola
D3 En cola
D4 Final

El primer elemento en ingresar es el primero en ser atendido y salir.

En Sistemas: Peticiones al Servidor

Modelo clásico de atención de solicitudes en redes, colas de impresión y eventos de usuario:

C3 C2 C1
SERVIDOR
¡Atendiendo C1!

Usos frecuentes: Cola de impresión (Spooler), buffer del teclado en el SO, tareas en background.

TDA Cola: Especificación

Operaciones Primitivas

Implementar el TDA Cola con un arreglo estático de enteros y su contador de elementos. Debe proveer las siguientes operaciones:

  • Cola crear(): inicializa y retorna una cola vacía (cantidad en 0).
  • bool vacia(Cola c): devuelve true si no hay elementos en la cola.
  • bool llena(Cola c): devuelve true si se completó la capacidad máxima.
  • void encolar(Cola &c, int elem): añade un elemento al final de la cola (push).
  • void desencolar(Cola &c): retira el elemento frontal de la cola (pop).
  • int frente(Cola c): devuelve el elemento frontal sin retirarlo (front).

Solución: TDA Cola


const int MAX_COLA = 100;

struct Cola {
    int datos[MAX_COLA];
    int cant;
};

Cola crear() {
    Cola c;
    c.cant = 0;
    return c;
}

bool vacia(Cola c) {
    return c.cant == 0;
}

bool llena(Cola c) {
    return c.cant == MAX_COLA;
}

void encolar(Cola &c, int elem) {
    if (!llena(c)) {
        c.datos[c.cant] = elem;
        c.cant++;
    }
}

void desencolar(Cola &c) {
    if (!vacia(c)) {
        for (int i = 0; i < c.cant - 1; i++) {
            c.datos[i] = c.datos[i + 1];
        }
        c.cant--;
    }
}

int frente(Cola c) {
    int elem = -1;
    if (!vacia(c)) {
        elem = c.datos[0];
    }
    return elem;
}
